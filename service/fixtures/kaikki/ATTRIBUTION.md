# kaikki-100.jsonl

100 строк английского дампа kaikki.org (https://kaikki.org/dictionary/English/), без тяжёлых полей
(этимология, переводы и т. п.). Данные получены из английского Wiktionary проектом wiktextract
и распространяются по лицензии [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/);
авторы статей — участники Wiktionary. Файл — производная работа и распространяется на тех же
условиях.

# kaikki-forms.jsonl

39 строк того же дампа для тестов `en-forms`: статьи go, went, child, children, good, well, better,
leave, left (по страницам слов kaikki.org, тяжёлые поля убраны). Источник и лицензия — те же,
CC BY-SA 4.0.
