## Проблема

Профиль пишут так: `save((await get()).copyWith(...))`. Две такие записи одновременно теряют одну из правок. Пример: тоггл подсветки в листе «Text» сохраняется сразу, а размер шрифта — с задержкой; совпали по времени — одна из правок пропала. Так же работают экран настроек, «Day / Night», шпаргалка.

## Что сделать

- В порт `ProfileRepository` — `Future<UserProfile> update(UserProfile Function(UserProfile) change)`: читает, применяет `change` и сохраняет без чужих записей между ними; возвращает новый профиль.
- `storage_drift`: внутри одной транзакции. Фейк: последовательно (очередь).
- Все записи профиля в фичах переходят на `update` с изменением только своего поля. `save` остаётся для начальной записи и тестов.

## Готово, когда

- Контрактный тест `ProfileRepository`: 20 параллельных `update`, каждый меняет своё поле или счётчик, — ни одна правка не потеряна; для фейка и drift.
- `grep` по `app/packages/features/*/lib` не находит `save(` с `get()` профиля; только `update`.
- Существующие тесты фич зелёные.
- `DECISIONS.md` `core`, `storage_drift` и затронутых фич дополнены.
- `app/scripts/check.sh` зелёный.
