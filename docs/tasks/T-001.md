## Что сделать

- Создать pub workspace в `app/` без melos.
- Пакеты-заглушки: `packages/core` (чистый Dart), `packages/core_testing`, `packages/reader_api`, `packages/storage_drift`, приложение `app/app`.
- Общий `app/analysis_options.yaml` уже лежит в репозитории (`very_good_analysis` + строгие режимы). Добавить `very_good_analysis` в `dev_dependencies` корневого `app/pubspec.yaml`. Не ослаблять правила; пакеты подхватывают файл сами.
- В `app/app` — пустой экран «My reader», сборка под macOS. Android добавим после MVP.
- `app/README.md`: как собрать и запустить.

## Готово, когда

- `flutter build macos` проходит, приложение запускается на Mac.
- `dart test` в `core` проходит (один тест-заглушка).
- `core/pubspec.yaml` не зависит от Flutter.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
