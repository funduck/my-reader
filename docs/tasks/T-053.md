- `LevelCheatSheetGenerator implements CheatSheetGenerator`: токены → леммы → уровни; оставить выше уровня пользователя; убрать имена собственные (слово с заглавной не в начале предложения) и уже запрошенные леммы из `TermRepository`.
- Ранжирование: уровень выше, Zipf ниже, частота в куске выше. Топ-15.
- `BuildCheatSheet`: кусок (T-052) → генератор → к каждому слову первое предложение из куска; толкование подтягивается провайдером при показе.
- Параметры (15, правила) — константы в одном месте.
