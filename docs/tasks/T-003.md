## Что сделать

- Типизированные id (`BookId` и т. п.) — обёртки над `String`.
- `Book`, `BookFormat`, `BookMetadata`, `TocEntry`, `ChapterRef`, `Locator`, `TextQuote`, `ReadingProgress`.
- `ContentDocument`: блоки (абзац, заголовок с уровнем, цитата, список, картинка) и инлайны (текст, курсив, жирный, ссылка).
- Ручные `==`, `hashCode`, `copyWith`, `toJson`/`fromJson` для `Locator` и `TextQuote` (они хранятся JSON-колонками).
- Экспорт через `lib/domain_books.dart`.

## Готово, когда

- Юнит-тесты на равенство и JSON-туда-обратно для `Locator`.
- `TextQuote.fromText(text, start, end)` строит цитату по правилам из README задач.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
