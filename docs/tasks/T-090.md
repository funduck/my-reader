## Что сделать

**Раскладка.** Первая строка: слово слева; уровень и переключатель режима — у правого края. Сразу под словом — перевод. Переключатель компактный: одна маленькая кнопка с текущим режимом (`RU` / `EN`), нажатие переключает на другой. Подсказка (`tooltip`, `Semantics`) — полное название: «English → Russian», «English → English».

**Когда переключатель виден** (решение человека: «скрывать, если там нет провайдера; дизейблить, если не нашёл ничего»):
- ни один провайдер не поддерживает другой режим (`supports(mode)`) — переключатель **скрыт**;
- провайдер есть — переключатель виден. Модалка сразу, параллельно с основным запросом, ищет слово и в другом режиме, только у офлайн-провайдеров (`ProviderInfo.isOnline == false`). Пока ответа нет, переключатель активен;
- в другом режиме ничего не нашлось (`LookupNotFound` у всех) — переключатель **неактивен** (`onPressed: null`);
- переключили режим — показывается уже готовый результат, без второго запроса.

Фоновый запрос другого режима не пишется в историю: правило T-086 (2 с на экране) действует только для показанного результата.

**Уровень** — тот же `LevelBadge`, рядом с переключателем.

## Готово, когда

- Widget-тесты:
  - нет провайдера для другого режима — переключателя нет;
  - провайдер есть — переключатель есть, нажатие показывает результат другого режима без нового вызова провайдера;
  - другой режим ничего не нашёл — переключатель неактивен;
  - результат другого режима не записан в историю, пока его не показали на 2 с;
  - перевод идёт сразу под строкой со словом (проверка порядка виджетов или golden).
