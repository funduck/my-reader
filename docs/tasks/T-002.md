## Что сделать

- Скрипт `app/scripts/check.sh`: `dart format --set-exit-if-changed`, `flutter analyze`, тесты всех пакетов.
- Проверка импортов (простой Dart-скрипт в `app/tool/check_imports.dart` по `pubspec.yaml` пакетов): `core` зависит только от Dart SDK и чистых утилит; адаптеры — только от `core`; `features/*` — от `core` и `reader_api`, но не от адаптеров; конкретные адаптеры подключает только `app/app`.
- Скрипт входит в `check.sh`.

## Готово, когда

- `check.sh` зелёный на текущем коде.
- Если добавить в `core` зависимость от `flutter`, `check.sh` падает с понятным сообщением.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
