## Баг

После «Знаю» в шпаргалке SnackBar с «Undo» висит, пока его не закроешь.

Причина: во Flutter 3.50 у `SnackBar` с `action` по умолчанию `persist: true` (`persist ?? action != null` в `snack_bar.dart`). Такой SnackBar не закрывается по таймеру. Так же устроены SnackBar с «Undo» в истории: удаление фразы (T-095) и снятие «Знаю» (T-098).

## Что сделать

- Во всех трёх SnackBar с «Undo» задать `persist: false`, чтобы они закрывались через 4 с, как обычные.
- Найти другие `SnackBar` с `action` в пакетах из «Где» и сделать то же.

## Готово, когда

- Widget-тесты для каждого из трёх SnackBar: после показа и `pump` на 5 с SnackBar на экране нет; «Undo» до этого по-прежнему работает.
- `DECISIONS.md` обоих пакетов дополнены одной строкой про `persist: false`.
- `app/scripts/check.sh` зелёный.
