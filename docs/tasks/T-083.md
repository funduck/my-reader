## Зачем

Читалка прокручивает главу, страниц нет. Настоящая постраничная вёрстка — после MVP. Здесь — дешёвый вариант: тап по краю прокручивает на экран.

## Что сделать

**Зоны.** При `edgeTaps == true`: правая четверть ширины вида — «вперёд», левая четверть — «назад», середина — как сейчас (тап по слову → толкование).
- Тап в зоне не даёт `WordTapped`, даже если попал в слово.
- Выделение текста работает во всех зонах: двойной клик и протяжка выделяют, как раньше, и листания не вызывают.
- Тап, который снимает выделение, не листает (как и сейчас не даёт события).
- Задержка `kDoubleTapTimeout` для тапов в зонах не нужна: листание сразу.

При `edgeTaps == false` всё как раньше.

**Клавиши** (работают всегда, вид должен держать фокус): `→`, `PageDown`, пробел — вперёд; `←`, `PageUp`, `Shift+пробел` — назад.

**Шаг.** Высота вида минус одна строка основного текста (`fontSize × lineHeight`), чтобы последняя строка экрана стала первой на следующем. Анимация 150 мс, `Curves.easeOut`. При `MediaQuery.disableAnimations` — без анимации.

**Края главы.** Вперёд, когда конец главы уже на экране, — `openNext` (как кнопка «Next chapter», с `ChapterFinished`). Назад в начале главы — `openPrevious`, позиция в конце предыдущей главы. Если в `openPrevious` нет способа открыть главу с конца, открыть с начала и описать это в отчёте.

После листания `PositionChanged` уходит по обычным правилам (T-017).

**Настройки** — переключатель «Листать тапом по краю экрана» в секции «Чтение».

## Готово, когда

Виджет-тесты `reader_simple` на главе из 200 абзацев:
- тап в правой четверти сдвигает первую видимую строку вперёд на высоту вида минус одна строка, с погрешностью не больше одной строки;
- тап в левой четверти возвращает назад;
- тап в зоне по слову не даёт `WordTapped`, тап по слову в середине даёт;
- двойной клик в зоне выделяет слово и не листает;
- `PageDown` и `PageUp` листают так же, как тапы;
- вперёд в конце главы даёт `ChapterFinished` и открывает следующую;
- при `edgeTaps == false` тап в правой четверти по слову даёт `WordTapped` и не листает.

Тест `features_settings`: переключатель сохраняет `display.edgeTaps`. `app/scripts/check.sh` зелёный.

## Не входит

- Выравнивание по строке, чтобы нижняя строка не разрезалась пополам. Нужно ли — решается в U-7.
- Жест по левому краю для яркости, анимация перелистывания, настоящие страницы.

## Важно

- Может конфликтовать с T-082 в `features/settings` и `reader_simple` (разные места файлов). Конфликт разрешает оркестратор, сохраняя обе правки.
- Если тап в зоне нельзя отделить от тапа по слову, не ломая выделение, — стоп и отчёт с тем, что пробовали.
