## Что сделать

- Команда `build fetch`: скачать английский дамп kaikki.org в `service/data/` с докачкой, записать версию (дату дампа).
- Потоковый парсер JSONL → датаклассы с нужными полями: слово, часть речи, `senses` (толкования, примеры), `sounds` (IPA), `forms`, `translations` (только `ru`).
- Тест на фрагменте из 100 строк в `fixtures/`.

## Готово, когда

- Парсер проходит весь дамп без падений, выводит число записей.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
