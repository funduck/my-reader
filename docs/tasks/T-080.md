## Зачем

Сейчас у `ReaderSettings` есть шрифт, размер, тема и поля, но межстрочный интервал — константа `ReaderStyle.lineHeight`, цвета зашиты в `ReaderStyle.fromSettings`, а сами настройки нигде не хранятся. Задача готовит модель и отрисовку. UI и проводка — в T-081.

## Что сделать

**core** — `DisplayPrefs` в `domain/profile/display_prefs.dart`, поле `UserProfile.display` (по умолчанию `const DisplayPrefs()`). Ручные `==`, `hashCode`, `copyWith`, `toJson`, `fromJson`: битые или отсутствующие поля берут значение по умолчанию, профиль без `display` читается. Хранится в том же JSON профиля, миграция drift не нужна.

| Поле | Тип | По умолчанию | Ограничения |
|---|---|---|---|
| `fontSize` | `double` | 18 | 12…40 |
| `lineHeight` | `double` | 1.5 | 1.0…2.5 |
| `mode` | `DisplayMode { day, night }` | `day` | |
| `day` | `Palette(text, background)`, ARGB `int` | `0xFF212121` / `0xFFFFFBF5` | |
| `night` | `Palette` | `0xFFE0E0E0` / `0xFF121212` | |
| `texture` | `BackgroundTexture`: sealed `NoTexture` / `BuiltInTexture(id)` / `FileTexture(path)` | `NoTexture` | |
| `textureOpacity` | `double` | 0.5 | 0…1 |
| `dim` | `double`, доля затемнения | 0 | 0…0.8 |
| `edgeTaps` | `bool`, листание тапом по краю | `true` | |

Значения вне диапазона `fromJson` и конструктор зажимают в диапазон (`clamp`). Текстура и затемнение — общие для обоих режимов: яркость и шум на практике меняют вместе с режимом редко. Если окажется не так, это решается в U-7.

**reader_api** — `ReaderSettings` получает `lineHeight`, `text`, `background` (`Color`), `texture` (`ImageProvider?`), `textureOpacity`, `dim`, `edgeTaps`. `theme` остаётся: от него зависят производные цвета. Значения по умолчанию совпадают с дневными из таблицы. `copyWith` для `texture` — через функцию, как `serviceUrl` в `UserProfile`, чтобы можно было сбросить в `null`.

**reader_simple** — `ReaderStyle.fromSettings`:
- `text` и `background` берутся из настроек;
- `muted` — `Color.lerp(text, background, 0.45)`;
- `link` — синий: `0xFF1565C0` днём, `0xFF90CAF9` ночью;
- `highlight` — как сейчас, по `theme`;
- `body.height` — `settings.lineHeight`. Константа `lineHeight` удаляется.

Отрисовка в `ReaderView`:
- Затемнение — `IgnorePointer` + `ColoredBox(Colors.black.withValues(alpha: dim))` поверх всего вида; при `dim == 0` слоя нет.
- Текстура — под списком блоков, вне прокрутки: `DecorationImage(image: texture, repeat: ImageRepeat.repeat, opacity: textureOpacity)` поверх цвета фона, в `RepaintBoundary`. Днём — `BlendMode.multiply`, ночью — `BlendMode.screen`. При `texture == null` — только цвет, как сейчас.
- `edgeTaps` в этой задаче только хранится, листание — в T-083.

`applySettings` по-прежнему не перестраивает главу и не сбивает позицию: ключ `_ChapterList` от стиля не зависит.

## Готово, когда

- Тесты `core`: `DisplayPrefs` туда-обратно через JSON; профиль без `display` и с битыми полями читается с умолчаниями; значения вне диапазона зажимаются.
- Тесты `reader_simple`:
  - `ReaderStyle.fromSettings` берёт цвета и интервал из настроек, `muted` между текстом и фоном;
  - виджет-тест: после `applySettings` с другим `lineHeight` и цветом фона `TextStyle.height` и цвет фона в дереве новые, первый видимый блок тот же;
  - при `dim > 0` есть слой затемнения, и тап по слову через него по-прежнему даёт `WordTapped`;
  - при заданной `texture` в дереве есть `DecorationImage` с `ImageRepeat.repeat` и нужной прозрачностью, вне `Scrollable`.
- `app/scripts/check.sh` зелёный.

## Важно

- Тексты и иконки UI — не в этой задаче.
- Если `DecorationImage.opacity` вместе с `BlendMode` даёт не то, что ожидается (проверить глазами в песочнице нельзя), выбрать вариант, который проходит тесты, и описать его в отчёте. Подбирать будет человек в U-7.
