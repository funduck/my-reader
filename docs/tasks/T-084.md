## Что сделать

В секции «Чтение» — строка «Шрифт»:
- кнопка «Папка со шрифтами…» открывает выбор папки (`file_selector`, `getDirectoryPath`);
- приложение ищет в папке и подпапках файлы `.ttf` и `.otf` (`.ttc` пропускает — `FontLoader` их не грузит);
- выпадающий список найденных шрифтов. Первый пункт — «Системный» (сейчас по умолчанию). Название — имя семейства и начертания из таблицы `name` файла (nameID 16/17, иначе 1/2); не прочиталось — имя файла. Список отсортирован, дубли по имени убраны;
- образец абзаца в секции рисуется выбранным шрифтом.

Хранение:
- в `DisplayPrefs` — `font`: `null` (системный) или путь к копии файла и имя семейства. Миграции drift нет: поле в JSON профиля, старый профиль без поля читается как `null`;
- выбранный файл копируется в `<support>/fonts/<sha256>.<ext>`, как картинка-фон. Причина: в песочнице macOS доступ к выбранной папке живёт до перезапуска. Прежняя копия удаляется при смене шрифта;
- путь к последней папке тоже сохраняется. При открытии настроек список строится из неё; если папка не читается — список пуст и подсказка «Выбери папку ещё раз».

Отрисовка:
- шрифт регистрируется через `FontLoader` под своим именем семейства до первой отрисовки читалки и после смены в настройках; `readerSettingsFrom` передаёт его в `fontFamily`;
- файл пропал или не загрузился — системный шрифт и `warning` в лог, без падения;
- выбор шрифта пишет в лог `info`: имя и файл.

Жирный и курсив в книге при этом синтезируются из одного файла. Подбор начертаний — вне задачи.

На Android `getDirectoryPath` отдаёт URI SAF, а не путь, и `dart:io` его не прочитает. На Android вместо папки — кнопка «Файлы шрифтов…» с выбором нескольких файлов через `file_picker`; список строится из выбранных файлов. Остальное то же.
