## Что сделать

- Сценарии `OpenBook` и `SaveProgress` в `core` с тестами.
- Экран: движок из `ReaderEngineFactory`, оглавление в боковой панели, переход по главам.
- Восстановление позиции при открытии, сохранение с дебаунсом 1 с и при сворачивании приложения.
- Параметр маршрута `locator` открывает книгу в этом месте (нужно для истории).

## Готово, когда

- Вручную на телефоне: открыть книгу, закрыть приложение, открыть — та же позиция.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.

## Важно

- Задача правит `app/app/lib/bootstrap.dart`. При слиянии возможен конфликт с другими такими задачами — разрешать, сохраняя обе правки.
