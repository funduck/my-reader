## Что сделать

- Сценарий `ImportBook` в `core`: подбор адаптера, метаданные, копирование файла под именем-хешем, сохранение `Book`. Тест на фейках.
- Экран библиотеки: кнопка импорта (`file_picker`), список книг с названием, автором и процентом.
- Тап по книге → маршрут `/reader/:bookId`.
- Подключить `EpubFormatAdapter` и drift-репозитории в `bootstrap.dart`.
- macOS: entitlement `com.apple.security.files.user-selected.read-only`, иначе диалог выбора файла не откроется.

## Готово, когда

- Widget-тест на фейках; вручную: импорт EPUB на macOS.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.

## Важно

- Задача правит `app/app/lib/bootstrap.dart`. При слиянии возможен конфликт с другими такими задачами — разрешать, сохраняя обе правки.
