## Что сделать

- **Снимок только по «Читать».** `CheatSheetSnapshot` пишется в `cheatSheetLogProvider` один раз, при нажатии «Читать»: книга, `clock.now().toUtc()`, тексты строк, показанных в этот момент (с учётом уровня, лимита, «Знаю», куска). Пустой показанный список пишется как пустой снимок. Пока список грузится или в ошибке, «Читать» ведёт в читалку без записи.
- **Выход без «Читать»** («назад», жест, закрытие) снимок не пишет: последней остаётся прежняя шпаргалка.
- **Нет записи при показе.** `cheatSheetSnapshotSaverProvider` больше не пишет на каждое изменение; убрать его или заменить действием.
- **Кнопка в конце списка.** «Читать» — последний элемент списка, а не закреплённая панель внизу экрана. Пустой список или ошибка — кнопка всё равно видна.
- Сбой записи — `warning` в лог, переход в читалку не отменяется. Переход идёт после записи (её `Future` дождаться), чтобы читалка сразу увидела новый снимок.

## Готово, когда

- Widget-тесты: открыл и ушёл «назад» — снимков нет; сменил уровень и нажал «Читать» — один снимок с текущим списком; пустой список — пустой снимок; ошибка записи — `onRead` всё равно вызван.
- Тест: «Читать» находится после последней строки списка (прокрутка до конца).
