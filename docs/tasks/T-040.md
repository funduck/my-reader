## Что сделать

- `HttpPackStore implements PackStore` на `package:http`.
- Скачивание во временный файл с прогрессом, проверка sha256, атомарная замена, версии установленных пакетов в `packs.json` рядом с файлами.
- Ошибки сети и несовпадение хеша — типизированные исключения.

## Готово, когда

- Тесты с `MockClient`: успешная загрузка, обрыв, неверный хеш, обновление версии.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
