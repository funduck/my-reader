## Что сделать

- `integration_test` на macOS: фикстурная книга → тап по слову → в модалке видно толкование → в базе есть `LookupEvent` с `Locator` и предложением; повторный тап увеличивает счётчик `Term`.
- Офлайн доказываем в самом тесте: HTTP-клиент подменён на такой, что падает при любом запросе. Пакеты — мини-фикстуры из `service/fixtures/`.
- Задержка: `Stopwatch` от тапа до кадра с толкованием, порог 300 мс на мини-пакете.
- Тот же замер на настоящем `en-en`: путь берётся из переменной окружения `EN_EN_PACK`, без неё тест пропускается. Его запускает человек на U-3.

## Готово, когда

- `flutter test integration_test -d macos` зелёный.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
