## Сейчас

Число слов выбирается переключателем «20 / 50 / Все» (`cheatSheetLimits`). По умолчанию 20.

## Что сделать

- **`core`, `UserProfile`.** `cheatSheetLimit` — целое число от 1 до 500, по умолчанию 10 (`defaultCheatSheetLimit`). Варианта «все» больше нет: поле не nullable, `cheatSheetLimits` удалить.
- **Старый JSON:**
  - нет ключа — 10;
  - `null` (раньше означал «все») — 500;
  - число вне 1..500 — ограничить до этого диапазона;
  - не число — 10.
- **Экран.** Вместо переключателя — числовое поле «Слов» (`TextField`, клавиатура цифр, только цифры) шириной на 3–4 цифры. Значение сохраняется в профиль, когда фокус уходит из поля или нажата Enter. Пустое значение или 0 — поле возвращается к сохранённому числу. Больше 500 — ставится 500. Список пересчитывается сразу после сохранения, как сейчас.

## Готово, когда

- Unit-тесты `UserProfile`: по умолчанию 10; JSON туда и обратно; старый JSON без ключа, с `null`, с 0, с 1000, со строкой.
- Widget-тесты экрана: ввод 7 и Enter — в списке 7 строк, профиль сохранён; ввод пустого значения — возврат к прежнему числу; ввод 999 — 500.
- `DECISIONS.md` `core` и `features_cheatsheet` дополнены.
