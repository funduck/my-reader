## Что сделать

- Экран настроек: адрес сервиса, режим по умолчанию, уровень, размер куска для шпаргалки (`pages(n)` или «до конца главы»).
- Раздел «Пакеты»: список из манифеста, статус, кнопка загрузки с прогрессом.
- macOS: entitlement `com.apple.security.network.client`. Адрес сервиса по умолчанию — `http://localhost:8080`.
- Подключить `HttpPackStore` в `bootstrap.dart`.

## Готово, когда

- Widget-тест на фейках; вручную на macOS: пакеты скачиваются с локального сервиса.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.

## Важно

- Задача правит `app/app/lib/bootstrap.dart`. При слиянии возможен конфликт с другими такими задачами — разрешать, сохраняя обе правки.
