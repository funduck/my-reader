## Замечание с U-3

Из приложения нельзя попасть в настройки и историю: маршруты `/settings` и `/history` есть, но кнопок к ним нет. Настройки открываются только из модалки слова через `context.go`, и из них нельзя вернуться: стек заменён, кнопки «Назад» нет.

## Что сделать

- Библиотека: в шапке кнопки «История» и «Настройки». Экран получает колбэки, как `onOpenBook`; навигацию делает `router.dart`.
- Читалка: те же два перехода в шапке (колбэки, как `onOpenCheatSheet`).
- Все переходы в настройки и историю — `context.push`, чтобы «Назад» возвращал на исходный экран. Это касается и `onOpenSettings` модалки (`bootstrap.dart`, `router.dart`).

## Готово, когда

- Тесты маршрутов: библиотека → настройки → назад → библиотека; библиотека → история → назад; читалка → настройки → назад → та же книга; модалка → настройки → назад → читалка.
- `app/scripts/check.sh` зелёный.

## Важно

- Задача правит `app/app/lib/bootstrap.dart`. При слиянии возможен конфликт с другими такими задачами — разрешать, сохраняя обе правки.
