## Что сделать

- `DisplayPrefs`: новое поле `translateOnSelect` (по умолчанию `false`), в `copyWith`, `==`, JSON. Старый JSON без поля читается как `false`.
- В AppBar читалки — переключатель «Translate» (иконка `translate`, вид «включено/выключено» не только цветом: заливка иконки или галочка). Нажатие меняет `DisplayPrefs` и сохраняет профиль, как кнопка «день/ночь».
- `ReaderScreen` передаёт значение в `ReaderSettings.translateOnSelect` при открытии книги и при изменении (как остальные настройки отображения).
- На телефоне переключатель виден только вместе с меню (T-087); на macOS — всегда.

## Готово, когда

- Unit-тесты `DisplayPrefs`: значение по умолчанию, JSON туда и обратно, старый JSON без поля.
- Widget-тест `ReaderScreen`: нажатие переключателя сохраняет профиль и вызывает `applySettings` с новым `translateOnSelect`; после перезапуска экрана (новый профиль из репозитория) значение то же.
