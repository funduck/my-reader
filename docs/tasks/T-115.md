## Что сделать

- **`HighlightPrefs`** в `core` (`@immutable`, ручные `==`, `copyWith`, `toJson`/`fromJson`), поле `UserProfile.highlights`:
  - `enabled` — все подсветки, по умолчанию `true`;
  - `difficult` (по умолчанию `false`), `cheatSheet`, `lookedUp`, `recent` (по умолчанию `true`);
  - `minFrequencyBars` — 1..5, по умолчанию 1 (то есть без фильтра, как сейчас).
- Профиль хранится в drift как JSON, поэтому схема не меняется; старый профиль без поля читается со значениями по умолчанию.
- **Порог частотности** фильтрует и шпаргалку: `selectCheatSheetItems(..., minBars:)` оставляет слова, у которых `zipfBars(zipf) >= minBars`; слова без `zipf` при `minBars > 1` отбрасываются. Шпаргалка берёт порог из профиля.
- Чистая функция `isDifficult(CheatSheetItem, {above, minBars, hidden})` для T-117 — то же правило, что у шпаргалки без лимита.
