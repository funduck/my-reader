## Что сделать

- `SimpleReaderEngine implements ReaderEngine`.
- Глава — ленивый `ListView.builder` по блокам, абзац — `SelectableText.rich` с курсивом, жирным, заголовками, картинками через `OpenedBook.resource`.
- `applySettings`: шрифт, размер, тема, отступы.
- Переход к следующей и предыдущей главе в конце и начале списка.
- Пример-приложение `example/` на `FakeOpenedBook`.
- Замер автоматический: `integration_test` на главе в 15 000 слов, `binding.traceAction` + `FrameTimingSummarizer`, запуск `flutter drive --profile -d macos`. Порог: 99-й процентиль кадра не хуже числа из отчёта спайка.

## Готово, когда

- Widget-тесты: блоки отрисованы, настройки применяются.
- Тест замера лежит в пакете, результат (числа) записан в README пакета.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.

## Важно

- Рендерер строится по выводу `REPORT.md`. Если вывод спайка не подтвердился на реальной главе — остановиться и описать расхождение, не менять подход самому.
