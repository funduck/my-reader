## Что сделать

- `ProviderChain`: порядок из профиля, фильтр по режиму, таймаут на провайдер, фолбэк на ошибку и пустой ответ.
- `LookupSelection`: строит `LookupQuery`, лемма через `TextAnalyzer`, вызывает цепочку (или явный `ProviderId`), пишет `LookupEvent`, делает `upsert` `Term`.
- Отмена через `CancelToken`.

## Готово, когда

- Тесты на фейках: фолбэк, таймаут, явный провайдер, событие записано даже при ошибке всех провайдеров.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
