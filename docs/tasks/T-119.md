## Что сделать

- `cheatSheet` — леммы последней шпаргалки книги (`CheatSheetLog.watch`).
- `lookedUp` — леммы слов, переведённых в этой книге после `shownAt` последней шпаргалки (`LookupJournal.watch(LookupFilter(book:, from:))`); без шпаргалки — все переводы книги. Новый перевод попадает в набор сразу после записи в журнал.
- Слова с пометкой «знаю» не подсвечиваются. Каждый вид выключается своим тогглом (T-115).
- Только текущая глава: набор лемм общий, движок сам находит их в главе (T-112).

## Готово, когда

- Widget-тест `ReaderScreen` с фейками: слова снимка — `cheatSheet`; перевод после снимка — `lookedUp`, до снимка — нет; новая шпаргалка сбрасывает `lookedUp`; тогглы выключают свои виды.
- `features/reader/DECISIONS.md` дополнен.
- `app/scripts/check.sh` зелёный.
