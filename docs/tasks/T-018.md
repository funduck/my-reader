## Что сделать

- Тап по слову → `WordTapped` (слово целиком, без пунктуации, `Locator`, предложение).
- Выделение фразы → кнопка в контекстном меню → `TextSelected`.
- Границы предложения — через `TextAnalyzer` из `core`, переданный в конструктор движка. В тестах — фейк.
- Подсветка `highlight(ranges)` — простой фон.

## Готово, когда

- Widget-тесты на тап, выделение и предложение на стыке абзацев.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
