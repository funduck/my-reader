## Что сделать

- `OpenedBook.spine` отдаёт главы по оглавлению верхнего уровня.
- Несколько глав в одном файле: режем `ContentDocument` по `id` якорей.
- Одна глава на несколько файлов: склеиваем файлы до следующего пункта оглавления.
- `chapter(ref)` возвращает ровно одну главу.

## Готово, когда

- Тесты на синтетических EPUB с обоими случаями.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
