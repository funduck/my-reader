## Что сделать

- `OpenedBook.spine` отдаёт главы по оглавлению верхнего уровня.
- Несколько глав в одном файле: режем `ContentDocument` по `id` якорей.
- Одна глава на несколько файлов: склеиваем файлы до следующего пункта оглавления.
- `chapter(ref)` возвращает ровно одну главу.

## Готово, когда

- Тесты на синтетических EPUB с обоими случаями.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.

## Решение оркестратора

- Подключить конвертер T-012: экспорт `ChapterContent`, `convertXhtml` в `lib/format_epub.dart`, `EpubBook.chapter` — `convertXhtml(readText(path), path: path).document`. `anchors` (id → индекс верхнего блока) нужны для нарезки глав по фрагментам оглавления.
- Именованные HTML-сущности (`&nbsp;`, `&mdash;`) сейчас дают `FormatException`: парсер XML строгий. Реальные EPUB их иногда содержат — обработать здесь или в T-014.
