## Что сделать

**Перевод `DisplayPrefs` → `ReaderSettings`** — функция в `features_reader`: `mode` → `theme` и палитра, цвета `int` → `Color`, `BuiltInTexture(id)` → `AssetImage('packages/reader_simple/assets/textures/<id>.png')`, `FileTexture(path)` → `FileImage(File(path))`, `NoTexture` → `null`. Список встроенных текстур до T-082 пуст. Шрифт (`fontFamily`) не трогаем.

**Читалка** (`features/reader`):
- `ReaderScreen` читает профиль через `profileRepositoryProvider.watch()` (`features_settings` импортировать нельзя) и вызывает `engine.applySettings` после `load` и при каждом изменении `display`.
- В шапке кнопка «день/ночь» (иконки `light_mode` / `dark_mode`, подсказка «Day / Night»): меняет `display.mode` и сохраняет профиль.
- В шапке кнопка «Аа» (подсказка «Text»): нижняя панель с быстрыми настройками — размер шрифта (кнопки «A−» / «A+», шаг 1), интервал (слайдер 1.0…2.5, шаг 0.1), затемнение (слайдер 0…0.8). Изменения видны сразу. Сохранение — с дебаунсом 300 мс, чтобы слайдер не писал в базу на каждом кадре.

**Настройки** (`features/settings`) — секция «Чтение» первой на экране:
- размер шрифта, интервал, затемнение — те же контролы, что в панели;
- режим — `SegmentedButton` «День» / «Ночь»;
- для каждого режима — палитра: ряд из 6 готовых пар «текст/фон» (кружки с образцом «Аа») и поле HEX для своего фона и своего текста. Готовые пары:
  - день: белый, сливочный `FFFBF5`, сепия `F4ECD8`, серый `E8E8E8`, мятный `E6F0E6`, голубой `E4ECF4` — текст `212121` или `3B2F2F` для сепии;
  - ночь: чёрный `000000`, графит `121212`, тёмно-серый `1E1E1E`, тёмная сепия `2B2419`, тёмно-синий `14181F`, тёмно-зелёный `16201A` — текст `E0E0E0` или `C8B89A` для тёмной сепии;
- образец абзаца под палитрой в выбранных цвете и размере;
- при контрасте текста к фону меньше 4.5:1 — предупреждение под образцом (не запрет).

**Тема приложения** (`app/app/lib/app.dart`): `themeMode` — из `display.mode` (день → `light`, ночь → `dark`), чтобы шапка, модалка и настройки шли за режимом читалки. Профиль ещё не прочитан — `ThemeMode.system`.

## Готово, когда

- Тест `features_reader`: при открытии книги движок получает `applySettings` с настройками из профиля; смена профиля (фейковый репозиторий) даёт новый `applySettings`; кнопка «день/ночь» сохраняет профиль с другим `mode`; слайдер в панели сохраняет профиль один раз после дебаунса, а не на каждое изменение.
- Тест `features_settings`: выбор готовой палитры и ввод HEX сохраняют `display.day` / `display.night`; неверный HEX не сохраняется и показывает ошибку; предупреждение о контрасте появляется для `777777` на `888888` и не появляется для готовых пар.
- Тест `app`: при `display.mode == night` у `MaterialApp` `themeMode == ThemeMode.dark`.
- `app/scripts/check.sh` зелёный.

## Важно

- Кнопки в шапке читалки — рядом с теми, что добавила T-101. Без колбэков, ничего не открывают через `router.dart`.
- Контраст — по формуле WCAG (относительная яркость), без пакетов.
