## Замечание с U-5

Словарь «English-Русский FreeDict+WikDict (en-ru)» (`sametypesequence=h`) показывается склеенным: «nounsomething that inspires fearжу́пелпу́гало…». `SimpleHtml` переносит строку только на `br`/`p`, а `div`, `ol`, `li` выбрасывает без разделителя. Статья `scare` из этого словаря:

```html
<div>/<font color="gray">skeə</font>/, /<font color="gray">skeɹ</font>/<br>
<div><font class="grammar" color="green">noun</font></div><ol><li>something that inspires fear<ol><li><div>жу́пел</div></li><li><div>пу́гало</div></li></ol></li><li>minor fright<ol><li><div>страх</div></li><li><div>испу́г</div></li><li><div>па́ника</div></li></ol></li></ol></div>
<div>/<font color="gray">skeə</font>/<br>
<div><font class="grammar" color="green">verb</font></div>to frighten<ol><li><div>пуга́ть</div></li><li><div>испуга́ть</div></li></ol></div>
```

## Что сделать

- Блочные теги (`div`, `p`, `ol`, `ul`, `li`, `h1`–`h6`, `tr`, `blockquote`) начинают новую строку; пустые строки подряд схлопываются, ведущих и хвостовых нет.
- `li` в `ol` — номер «1.», в `ul` — «•»; вложенные списки — с отступом на уровень.
- `font color` можно игнорировать; текст не теряется.
- Без пакетов вроде `flutter_html`.
