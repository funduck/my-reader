## Что сделать

- `bootstrap.dart`: `ProviderScope(overrides: [...])`, пока с фейками из `core_testing` там, где нет реализаций.
- Riverpod-провайдеры портов объявить в маленьком пакете `packages/features/common` (или в `core`-совместимом месте), чтобы фичи не зависели от `app`.
- `go_router`: маршруты `/library`, `/reader/:bookId?locator=…`, `/settings`, `/history`, `/cheatsheet/:bookId` с экранами-заглушками.
- Светлая и тёмная тема по системе.

## Готово, когда

- Приложение запускается, по всем маршрутам открываются заглушки.
- Widget-тест: роутер открывает каждый маршрут.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.

## Важно

- Задача правит `app/app/lib/bootstrap.dart`. При слиянии возможен конфликт с другими такими задачами — разрешать, сохраняя обе правки.
