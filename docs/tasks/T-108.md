## Что сделать

Защита от перевода больших кусков: DeepL тратит квоту по символам.

- **`core`.** `TranslatePhrase` проверяет выделение до запроса к DeepL. Если `TextAnalyzer.sentences(text)` даёт больше одного предложения, результат — `PhraseFailed(kind: PhraseFailureKind.tooLong)`. Провайдер не вызывается, в журнал ничего не пишется.
- **Запасной предел.** Предложение длиннее 500 символов — тоже `tooLong`: бывает текст без точек.
- **Модалка.** Для `tooLong` — сообщение «Select one sentence at most», без «Retry».

## Готово, когда

- Unit-тесты `TranslatePhrase`:
  - два предложения — `tooLong`, фейковый провайдер не вызван, записи нет;
  - одно предложение — перевод как раньше;
  - одно предложение длиннее 500 символов — `tooLong`;
  - фраза из двух слов внутри предложения — перевод.
- Widget-тест модалки: выделение из двух предложений — сообщение, без «Retry», провайдер не вызван.
