## Что сделать

- Команда `build all`: собрать все пакеты и `manifest.json` (id, версия, размер, sha256, путь).
- Команда `serve`: раздача `service/data/out/` на `127.0.0.1:8080`. Флаг `--lan` слушает `0.0.0.0` — понадобится телефону после MVP.
- Инструкция в `service/README.md`.

## Готово, когда

- `curl http://localhost:8080/manifest.json` отдаёт манифест.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
