## Что сделать

- Команда `build all`: собрать все пакеты и `manifest.json` (id, версия, размер, sha256, путь).
- Команда `serve`: раздача `service/data/out/` на `0.0.0.0:8080`, печать адреса Mac в локальной сети.
- Инструкция в `service/README.md`.

## Готово, когда

- С телефона в той же сети `curl http://<mac>:8080/manifest.json` отдаёт манифест.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.
