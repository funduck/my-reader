## Зачем

Экран шпаргалки (T-099) будет менять уровень, лимит и прятать слова «знаю» без повторного разбора текста. Для этого генератор один раз отдаёт всех кандидатов с уровнем и частотностью, а отбор и сортировка — дешёвая чистая функция над списком.

## Что сделать

- **`CheatSheetItem.zipf`** (`double?`) — частотность из `WordLevel.zipf`. Учесть в `==` и `hashCode`.
- **Генератор отдаёт всех кандидатов.** `LevelCheatSheetGenerator` больше не режет по `cheatSheetMaxItems` и по уровню пользователя: в список идут все леммы с известным уровнем, кроме имён собственных и `knownTerms`. Параметр `userLevel` порта `CheatSheetGenerator` убрать или сделать необязательным, без изменения смысла остальных параметров.
- **Отбор — чистая функция** `selectCheatSheetItems(items, {required CefrLevel above, required int? limit, Set<String> hidden = const {}})`: только уровни строго выше `above`, без `hidden`, от частых к редким (`zipf` по убыванию; без `zipf` — в конец), при равенстве — прежний порядок генератора. `limit == null` — все.
- **Лимит в профиле.** `UserProfile.cheatSheetLimit` (`int?`, по умолчанию 20; `null` — «все»), JSON с обратной совместимостью: старый профиль без поля читается с 20. Допустимые значения: 20, 50, `null`; прочее читается как 20.
- **`BuildCheatSheet`** по-прежнему отдаёт `CheatSheet`, но уже со всеми кандидатами. Отбор по профилю делает экран.
- **Полоски частотности** — чистая функция `zipfBars(double? zipf) → int?`: `null` без `zipf`, иначе 1–5. Пороги: ≥ 5 → 5, [4; 5) → 4, [3; 4) → 3, [2; 3) → 2, < 2 → 1. Пороги — константы в `cheat_sheet_config.dart`.
- **Короткая цитата** — чистая функция `shortQuote(String sentence, String word, {int window = 7})`: до `window` слов слева и справа от первого вхождения `word` (без учёта регистра, по границе слова), не выходя за предложение. Где текст обрезан, ставится «…». Если слово не найдено — предложение целиком. Генератор кладёт в `CheatSheetItem.example` короткую цитату вокруг словоформы из текста (не леммы).

## Готово, когда

- Unit-тесты: `selectCheatSheetItems` (уровень, лимит, `hidden`, сортировка по `zipf`, слова без `zipf` в конце); `zipfBars` на каждом пороге и `null`; `shortQuote` (слово в начале, в середине, в конце, пунктуация рядом со словом, слово дважды, слово не найдено, короткое предложение без «…»); JSON профиля без `cheatSheetLimit`.
