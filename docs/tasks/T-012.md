## Что сделать

- Перевод XHTML в блоки и инлайны `ContentDocument`. CSS игнорируем.
- `p`, `h1–h6`, `blockquote`, `ul/ol/li`, `img`, `br`, `em/i`, `strong/b`, `a`. Неизвестные теги — разворачиваем в текст.
- Пробелы нормализуем как браузер. Сохраняем `id` элементов, чтобы на них можно было сослаться из оглавления.
- Сноски-ссылки оставляем ссылками.

## Готово, когда

- Тесты на каждый тег и на главу из реальной книги (снапшот).
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.

## Важно

- Работает параллельно с T-011 в том же пакете: трогать только `lib/src/content/` и `test/content/`. Общие фикстуры из `test/fixtures/` (T-010) только читать.
