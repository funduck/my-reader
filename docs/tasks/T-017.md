## Что сделать

- Внутренняя позиция — индекс блока + смещение символа. Первый видимый блок и возврат к блоку — приёмом из `spikes/reader/REPORT.md`; смещение внутри длинного абзаца восстанавливается по `TextQuote`.
- `PositionChanged` с `Locator` (глава, `progression`, `TextQuote` первой видимой строки, `engineHint`) — не чаще раза в 500 мс.
- `load(book, at:)` и `goTo(locator)`: сначала `engineHint`, затем поиск по `TextQuote`, затем `progression`.

## Готово, когда

- Тесты: позиция → `Locator` → `goTo` возвращает на тот же блок; при битом `engineHint` работает поиск по цитате.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.

## Решение оркестратора

- Движку нужен `BookId` для `Locator` в событиях. `ReaderEngine.load` получает обязательный именованный `BookId bookId`: `load(OpenedBook book, {required BookId bookId, Locator? at})`. Правка `reader_api` и `SimpleReaderEngine` — в этой задаче.
