## Что сделать

**Встроенные текстуры.** Три бесшовные картинки 256×256 в оттенках серого, PNG, каждая меньше 100 КБ: `paper` (мягкий шум с крупными волокнами), `noise` (мелкий равномерный шум), `linen` (лёгкая сетка). Генерирует их скрипт `app/tool/gen_textures.dart` на `package:image` (dev-зависимость корня workspace, как `yaml` для `check_imports.dart`) с фиксированным seed, без загрузки чего-либо из сети. Бесшовность: шум строится на торе (значения по краям совпадают), не обрезкой. Средняя яркость около 50 % серого, разброс небольшой: текстура должна быть едва заметна при прозрачности 0.5. Файлы — в `app/packages/reader_simple/assets/textures/`, объявлены в `pubspec.yaml` пакета. Список id — константа `builtInTextures` в `reader_simple`.

**Своя картинка.**
- `backgroundsDirectoryProvider` (`Provider<String>`) в `features_settings`, как `booksDirectoryProvider` в `features_library`: без override бросает ошибку. В `buildDeviceOverrides` — `<applicationSupport>/backgrounds`, каталог создаётся при первой записи.
- Выбор файла — `file_selector` за `backgroundFilePickerProvider` (в тестах подменяется), фильтр `png`, `jpg`, `jpeg`, `webp`.
- Файл копируется в каталог под именем `<sha256>.<ext>`, в профиль пишется `FileTexture(<новый путь>)`. Старый свой файл, если он больше не используется, удаляется.
- Файл больше 5 МБ не принимается, показывается сообщение.
- Отсутствующий файл (удалён руками) — фон без текстуры, без падения. В лог — `warning`.

**Настройки** — в секции «Чтение»: ряд образцов «Без текстуры», три встроенные, «Своя…». Под ним слайдер «Заметность текстуры» (`textureOpacity`). Образцы рисуются на фоне текущего режима.

## Готово, когда

- Скрипт `gen_textures.dart` детерминирован: два запуска дают побайтно одинаковые файлы (тест в `app/tool/`), и левый край каждой текстуры совпадает с правым, верхний — с нижним (тест по пикселям).
- Тест `features_settings`: выбор встроенной текстуры сохраняет `BuiltInTexture(id)`; «Своя…» с фейковым пикером копирует файл во временный каталог и сохраняет `FileTexture`; файл больше 5 МБ отклоняется; замена своей картинки удаляет прежний файл.
- Тест `features_reader`: `FileTexture` с отсутствующим файлом даёт `ReaderSettings.texture == null`.
- `app/scripts/check.sh` зелёный.

## Важно

- Задача правит `app/app/lib/bootstrap.dart`. При слиянии возможен конфликт с другими такими задачами — разрешать, сохраняя обе правки.
- Если `package:image` не ставится в песочнице — стоп и отчёт, не рисовать PNG вручную байтами.
