## Что сделать

- Подключить `formatAdapterContract` из `core_testing`.
- Кривые фикстуры: нет `container.xml`, битый XML в главе, ссылка на отсутствующий файл, кодировка не UTF-8.
- Ошибки — типизированные исключения из `core`, без падений с `RangeError` и т. п.
- Кодировки: UTF-8 и UTF-16 (по BOM) — строго; `ISO-8859-1`/`latin1` из объявления XML — через `latin1`; прочие (например, `windows-1251`) и битый UTF-8 — `FormatException` с названием кодировки и пути. Тихой замены на U+FFFD нет.
