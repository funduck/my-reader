## Что сделать

- Python 3.12, `uv`, `ruff`, `pytest`. Структура `service/build`, `service/serve`, `service/data` (в `.gitignore`).
- Точная схема SQLite каждого пакета (`en-en`, `en-forms`, `en-levels`) и формат `manifest.json` — в `docs/Architecture-service.md`, раздел «Схемы пакетов».
- Тестовые мини-пакеты на 20–50 слов в `service/fixtures/` — их используют тесты приложения (T-043, T-044, T-050).

## Готово, когда

- `uv run pytest` зелёный.
- Схемы описаны так, чтобы по ним можно было написать Dart-код, не читая Python.
- `app/scripts/check.sh` (или `uv run pytest` для сервиса) зелёный.

## Важно

- Это контракт между сервисом и приложением. После слияния схему меняем только отдельной задачей.
