# Требования: читалка для изучения иностранного языка

## 1. Цель

Мобильная читалка, которая помогает учить язык во время чтения: переводит выделенное, запоминает каждый запрос с контекстом и превращает эти запросы в материал для повторения.

Приоритеты:
- **P0** — без этого продукта нет.
- **P1** — важно, делаем сразу после P0.
- **P2** — желательно, позже.

### Языки

На старте поддерживается один изучаемый язык — английский — в двух режимах:
- **EN → RU:** перевод на русский.
- **EN → EN:** толкование на английском, как в толковом словаре (Oxford, Cambridge и т. п.).

Пользователь выбирает режим по умолчанию и может переключить его прямо в модалке перевода.

## 2. Чтение

| ID | Требование | Приоритет |
|----|------------|-----------|
| R-1 | Открытие книг с устройства (минимум EPUB, затем FB2, TXT, PDF) | P0 |
| R-2 | Навигация по оглавлению и главам, запоминание позиции чтения | P0 |
| R-3 | Настройки отображения: шрифт, размер, тема (светлая/тёмная), отступы | P1 |
| R-4 | Библиотека: список книг, прогресс чтения | P1 |

## 3. Перевод по выделению (ключевая функция)

| ID | Требование | Приоритет |
|----|------------|-----------|
| T-1 | Выделение слова или фразы открывает модальное окно с переводом | P0 |
| T-2 | Тап по слову выделяет его целиком и сразу открывает перевод | P1 |
| T-3 | В модалке: перевод, транскрипция, часть речи, примеры (если провайдер их даёт) | P1 |
| T-4 | В модалке показывается уровень слова (C2/C1/B2/B1…), если он известен | P1 |
| T-5 | Из модалки можно закрыть окно, сменить провайдера, пометить слово как «знаю» | P1 |
| T-6 | В модалке переключается режим EN → RU / EN → EN | P1 |

### 3.1. Провайдеры перевода

| ID | Требование | Приоритет |
|----|------------|-----------|
| P-1 | Провайдеры подключаются через общий интерфейс (плагинная архитектура) | P0 |
| P-2 | Внешние онлайн-провайдеры (API переводчиков, LLM) с настройкой ключа пользователем | P0 |
| P-3 | Загружаемые офлайн-словари (скачать, обновить, удалить) | P1 |
| P-4 | Порядок провайдеров и фолбэк: если первый недоступен, используется следующий | P1 |
| P-5 | Работа без сети через офлайн-словари | P1 |

## 4. История запросов (самое важное)

Каждый запрос перевода сохраняется. Это основа для повторения и тестов.

| ID | Требование | Приоритет |
|----|------------|-----------|
| H-1 | Сохраняется каждый факт запроса: исходный текст, перевод, провайдер, дата и время | P0 |
| H-2 | Сохраняется привязка к месту: книга, глава, позиция в тексте, предложение-контекст | P0 |
| H-3 | Из записи истории можно перейти к месту в книге, где был запрос | P1 |
| H-4 | Повторные запросы одного слова агрегируются (счётчик, все контексты) | P1 |
| H-5 | Просмотр истории с фильтрами: по книге, главе, дате, уровню | P1 |
| H-6 | Экспорт истории (CSV, формат Anki) | P2 |

## 5. Повторение

| ID | Требование | Приоритет |
|----|------------|-----------|
| L-1 | Создание карточек из истории запросов: слово/фраза, перевод, контекст из книги | P0 |
| L-2 | Интервальное повторение карточек (алгоритм типа SM-2/FSRS) | P1 |
| L-3 | Тест в конце главы по словам, запрошенным в этой главе | P1 |
| L-4 | Типы заданий в тесте: выбор перевода, перевод в обратную сторону, пропуск в предложении из книги | P2 |
| L-5 | Результаты тестов влияют на расписание повторения | P2 |

## 6. Подготовка к чтению (шпаргалка)

По запросу пользователя приложение анализирует следующий фрагмент текста и показывает шпаргалку, чтобы читать было проще.

| ID | Требование | Приоритет |
|----|------------|-----------|
| S-1 | Шпаргалка строится по запросу пользователя, не автоматически | P1 |
| S-2 | Фрагмент анализа: следующая глава или отрезок фиксированной длины (настраивается) | P1 |
| S-3 | Определение уровня слов (C2/C1/B2/B1) по справочникам частотности/CEFR | P1 |
| S-4 | Выделение устойчивых выражений, идиом, фразовых глаголов | P1 |
| S-5 | Фильтр по уровню: показывать только слова выше уровня пользователя | P1 |
| S-6 | Исключение слов, помеченных как «знаю» и хорошо выученных | P2 |
| S-7 | Из шпаргалки можно добавить слово в карточки | P2 |

## 7. Профиль пользователя

| ID | Требование | Приоритет |
|----|------------|-----------|
| U-1 | Режим перевода: английский → русский или английский → английский (толкование) | P0 |
| U-2 | Текущий уровень пользователя (для фильтров шпаргалки) | P1 |
| U-3 | Список известных слов | P2 |

## 8. Нефункциональные требования

- **Платформа:** телефон (Android P0, IOS P2).
- **Офлайн:** чтение, история и карточки работают без сети.
- **Данные:** хранятся локально; синхронизация и бэкап — P2.
- **Скорость:** модалка перевода открывается мгновенно, результат из офлайн-словаря — до 300 мс.
- **Приватность:** ключи API хранятся в защищённом хранилище ОС.
