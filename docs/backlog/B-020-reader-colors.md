# B-020. Цвета читалки и подсветок, выбор цвета

**Статус:** открыт  
**Тип:** доработка  
**Связано с:** R-3 в [Requirements.md](../Requirements.md), [B-014](B-014-cosmetics.md), [B-019](B-019-text-highlights.md), [B-022](B-022-demo-app.md), `reader_api` (`ReaderSettings`), `features/settings`

## Что хотим

1. **Подобрать цвета по умолчанию** для фона и текста читалки (день и ночь) и для каждого вида подсветки из [B-019](B-019-text-highlights.md).
2. **Выбор цвета** в настройках: свободный выбор любого цвета (колесо или ползунки HSV) для:
   - фона страницы;
   - текста;
   - каждого вида подсветки.
3. Кнопка «по умолчанию», которая возвращает подобранные цвета.

Тема приложения (меню, кнопки, модалки) в эту задачу не входит.

## Анализ

- Сейчас цвета выводятся из темы (`ReaderSettings`: «derived colours (link, highlight) depend on it»). Нужны явные поля цветов в `ReaderSettings` и `DisplayPrefs`, отдельно для дня и ночи. Меняется контракт `reader_api`.
- Свободный выбор позволяет сделать нечитаемое сочетание. Показывать предупреждение, если контраст текста и фона ниже 4.5:1; цвет подсветки проверять против фона.
- Виджет выбора цвета: готовый пакет (`flex_color_picker`, `flutter_colorpicker`) или свой на ползунках HSV. Проверить зависимости пакета (правило про лишние зависимости в [AGENT.md](../tasks/AGENT.md)).
- Подбирать цвета удобнее в демо-приложении ([B-022](B-022-demo-app.md)) со всеми видами подсветки сразу.

## Вопросы

1. Цвета подсветки общие для дня и ночи или свои для каждого режима? Предполагаю свои: светлый фон подсветки на тёмной странице выглядит плохо.
2. Текстура (B-014, п. 1) накладывается поверх выбранного цвета фона или заменяет его?

## Результат

Задача на контракт и настройки цветов; подбор значений по умолчанию — после исследования визуала в B-019.
