# B-025. Перевод слова в контексте через LLM

**Статус:** открыт; ждёт онлайн-эндпоинта сервиса из [B-021](B-021-phrases-via-service.md)  
**Тип:** новая функция (приложение и сервис)  
**Связано с:** [B-021](B-021-phrases-via-service.md), [B-010](B-010-lookup-sheet-layout.md), `features/lookup_sheet`, `service/`

## Проблема

Словарная статья даёт все значения слова, и пользователь сам выбирает, какое подходит в этом предложении. Для многозначных слов и переносных значений это трудно.

## Что хотим

- В модалке перевода слова — кнопка «Перевод в контексте». Запрос уходит только по нажатию.
- Приложение отправляет на наш сервис: слово, предложение целиком и статью из словаря, которую сейчас показывает модалка.
- Сервис спрашивает LLM и возвращает короткий ответ: значение именно в этом предложении (перевод и, если нужно, пояснение).
- Ответ показывается в модалке отдельным блоком под словарной статьёй.
- Ключ LLM лежит на сервисе, в приложении его нет.

## Анализ

- **Сервис.** Эндпоинт рядом с переводом фраз из B-021: тот же хостинг, авторизация, лимиты и учёт запросов. Статья из словаря передаётся, чтобы LLM выбирал из известных значений, а не придумывал своё. Кэш по (лемма, предложение).
- **Приложение.** Новый вызов в `features/lookup_sheet` за портом в `core`; адаптер HTTP к сервису. Сеть или сервис недоступны — понятное сообщение в блоке, словарная статья остаётся.
- **История.** Решить, сохранять ли ответ LLM в событии запроса (H-1) и показывать ли его в истории и шпаргалке.
- **Приватность.** На сервис уходит предложение из книги. Правила хранения — те же, что в B-021.

## Вопросы

1. Модель и формат ответа (длина, язык пояснения: русский или английский по режиму модалки).
2. Сохранять ли ответ в истории.
3. Работает ли кнопка для фраз, или фразы целиком переходят на LLM в B-021.
