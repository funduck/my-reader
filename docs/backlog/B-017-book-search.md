# B-017. Поиск по книге

**Статус:** открыт  
**Тип:** новая функция  
**Связано с:** `features/reader`, `format_epub`

## Что хотим

Поиск слова или фразы по текущей книге:
- поле поиска из меню читалки;
- список совпадений: кусок текста вокруг совпадения (найденное выделено) и глава;
- тап — переход к месту, совпадение подсвечено (как переход из истории, T-071).

## Анализ (M)

- Поиск идёт по тексту всех глав, без учёта регистра; для фраз — с нормализацией пробелов и типографских апострофов (`’` = `'`).
- Главы загружаются лениво — поиск должен идти по главам в фоне, показывать результаты по мере нахождения и отменяться при новом запросе.
- Совпадение превращается в `Locator` (с `TextQuote`), дальше — `engine.goTo` и `highlight`.
