# B-015. Интерфейс на английском, строки в ARB

**Статус:** открыт  
**Тип:** доработка  
**Связано с:** все `features/*`

## Проблема

Строки интерфейса зашиты в код, языки перемешаны (например, `'Разминка'` рядом с `'History'` в меню читалки).

## Что хотим

- Весь интерфейс на английском.
- Все строки через `gen-l10n`: шаблон `app_en.arb`, `AppLocalizations`, `nullable-getter: false`. Плюрализация через ICU.
- Других языков пока нет; инфраструктура готова, чтобы добавить русский одним ARB-файлом.

## Анализ

- Где лежат ARB: один файл в `app/app` или по пакету в каждом `features/*` — решить в первой задаче и записать в `DECISIONS.md`.
- Тесты, которые ищут текст (`find.text('Разминка')`), придётся обновить.
- Можно делать по пакету, по задаче на пакет.
