# B-005. Импорт StarDict не работает на Android

**Статус:** done (2026-11-23, вариант 1: `file_picker`; проверено на Pixel)  
**Тип:** баг  
**Связано с:** [B-002](B-002-android-build-debt.md)

## Симптом

На телефоне (Pixel, release-сборка) выбор файлов словаря в настройках заканчивается ошибкой. В логе:

```
WARNING DictionariesController: Bad dictionary files
  error: FormatException: Missing .ifo file in the import set
```

## Причина

`DictionariesController` выбирает файлы через `file_selector` (`openFiles`). На Android плагин `file_selector_android` 0.5.2+11 копирует каждый выбранный файл в кэш приложения и **переименовывает** его: оставляет базовое имя и подставляет расширение, полученное из MIME-типа (`FileUtils.getPathFromCopyOfFileFromUri`). Для `.ifo`, `.idx`, `.dict.dz` MIME неизвестен (`application/octet-stream` или gzip), поэтому `dict.ifo` приходит под другим расширением. Настоящее имя (`DISPLAY_NAME`) плагин передаёт в Dart, но `XFile.name` его не использует, а берёт имя из пути.

`StarDictLibrary._pick` ищет файлы по суффиксу (`.ifo`, `.idx`, `.dict`/`.dict.dz`) и не находит `.ifo`. На macOS путь настоящий, поэтому там всё работает.

## Варианты

1. **Перейти на `file_picker`** (S). Он уже в зависимостях: им импортируются книги в `features_library`, и на Android импорт EPUB работает. При копировании он сохраняет исходное имя файла. Нужно проверить на телефоне выбор нескольких файлов сразу.
2. **Опознавать файлы по содержимому, а не по имени** (S–M). `.ifo` — текст, начинается с `StarDict's dict ifo file`; `.dict.dz` — gzip (`1f 8b`); `.idx` — всё остальное. Это не зависит от плагина и от того, как назовёт файл провайдер (Google Drive и т. п.).
3. **Импорт архивом** (M). Словари StarDict обычно распространяются архивами `.tar.bz2`/`.tar.gz`/`.zip`. Выбор одного файла удобнее на телефоне, чем выбор трёх. Нужна распаковка (пакет `archive`) и проверка размера.

Рекомендация: 1 сейчас, 2 как страховка в той же задаче; 3 отдельной задачей.

## Тесты

Юнит-тест `StarDictLibrary` на наборе с переименованными файлами (для варианта 2). Проверка на телефоне — руками.
