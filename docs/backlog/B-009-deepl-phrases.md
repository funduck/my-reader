# B-009. Перевод фраз через DeepL

**Статус:** done в M8 (T-091…T-095, 2026-11-23), кроме раздела «Потом»; настоящий DeepL не проверен руками  
**Тип:** новая функция  
**Связано с:** [B-008](B-008-selection-translate.md), P-2 в [Requirements.md](../Requirements.md), [Data-sources.md](../Data-sources.md) (DeepL API)

## Что хотим

Выделение больше одного слова переводится как фраза через DeepL.

- Ключ DeepL (Free или Pro) вводит пользователь в настройках. Хранится в защищённом хранилище ОС.
- Приложение ходит в DeepL API напрямую, без нашего сервиса.
- Нет ключа или сети: в модалке понятное сообщение и ссылка на настройки. Что предложить вместо перевода (перевод по словам из офлайн-словаря?) — решить в задаче.

## Хранение

Переводы фраз хранятся **отдельно от слов**, не как термины истории. Причина: одна и та же конструкция (фразовый глагол, идиома) встречается в разных формах (`gave up` / `giving it up`), и потом их надо склеивать. Простое совпадение строк этого не умеет.

Модель для фраз: текст, перевод, провайдер, время, контекст и место в книге (как H-1, H-2). Правило «на экране 2 с» (T-086) — такое же.

## Потом (не в этой задаче)

- **Фолбэк через наш сервис:** если у пользователя нет ключа, переводить через `service/`, где лежит ключ.
- **Склеивание вариантов фраз** почти наверняка требует сервера и LLM. Два пути: переводить фразы через сервер (он же склеивает) или отправлять сохранённые фразы на сервер, чтобы он склеивал. Выбрать, когда дойдём.
