# B-012. Тест после отрывка

**Статус:** открыт  
**Тип:** новая функция  
**Связано с:** L-3 в [Requirements.md](../Requirements.md), [B-011](B-011-cheatsheet-controls.md), [B-013](B-013-spaced-repetition.md)

## Что хотим

Читалка предлагает короткий тест, когда:
- читатель дошёл до конца отрывка, для которого смотрел шпаргалку, **или**
- с прошлого теста накопилось 20 переводов.

Предложение ненавязчивое (баннер или карточка внизу), его можно отклонить.

**Тест — самооценка.** В тест идут все переводы с прошлого теста (кроме помеченных «знаю»). Для каждого:
- слово и предложение-контекст из книги;
- «Показать перевод»;
- «Помню» / «Не помню»;
- галочка «В повторение» (для «не помню» включена по умолчанию).

В конце — итог и список с галочками «в повторение», их можно поправить перед сохранением.

## Анализ

- Конец отрывка шпаргалки: шпаргалка знает свой диапазон (`TextRange`); нужно запомнить его для книги и сравнить с `PositionChanged`.
- Счётчик «переводов с прошлого теста» — по журналу событий после времени последнего теста книги.
- Результаты «помню / не помню» пока только для отбора в повторение; влияние на расписание (L-5) — после [B-013](B-013-spaced-repetition.md).
- Новый пакет `features/quiz` или раздел в `features/history` — решить при разбиении на задачи.
