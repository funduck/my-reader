# B-016. Постраничное чтение

**Статус:** открыт  
**Тип:** новая функция (большая)  
**Связано с:** [T-083](../tasks/T-083.md) (отложена), [B-006](B-006-progress-bar.md), R-3 в [Requirements.md](../Requirements.md)

## Что хотим

Настоящие страницы вместо прокрутки:
- текст главы верстается в страницы под текущий экран и настройки;
- строки не режутся по горизонтали;
- листание свайпом и тапом по краю экрана;
- номер страницы и число страниц (для полосы в [B-006](B-006-progress-bar.md)).

## Анализ (L)

- `reader_simple` сейчас показывает главу как ленивый список блоков. Страницы — это либо новый движок за `ReaderEngine`, либо режим в `reader_simple`. Интерфейс `ReaderEngine` должен это позволять: проверить.
- Вёрстка: разбить блоки на страницы через `TextPainter` (измерить высоту, резать абзац по строкам). Пересчитывать при смене шрифта, размера, поворота экрана. Делать это в фоне, без блокировки UI.
- Число страниц всей книги требует вёрстки всех глав; можно считать лениво и показывать приблизительное, пока не досчитано.
- Позиция (`Locator`), подсветка, выделение и тап по слову должны работать как в режиме прокрутки.
- T-083 (дешёвый вариант: тап по краю прокручивает на экран) этой задачей заменяется.
