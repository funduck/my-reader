# B-014. Косметика: текстуры, настройки, меню, значения по умолчанию

**Статус:** открыт  
**Тип:** доработка  
**Связано с:** R-3 в [Requirements.md](../Requirements.md), [T-082](../tasks/T-082.md), `features/settings`, `features/reader`

## Что хотим

1. **Текстуры.** Убрать нынешние текстуры (`reader_simple/assets/textures`), найти 3–4 спокойные бумажные текстуры с лицензией CC0: светлые и тёмные для ночи. Текстура почти незаметна под текстом. Источник и лицензию записать в [Data-sources.md](../Data-sources.md).
2. **Настройки по секциям.** Например: «Чтение» (шрифт, размер, интервал, цвета, текстура, яркость), «Перевод» (режим, провайдеры, словари, ключ DeepL), «Шпаргалка» (уровень, лимит), «Данные». Окончательный список секций — в задаче.
3. **Кнопка «Text» уходит из верхнего меню читалки.** Шрифт, размер и интервал меняются только в настройках.
4. **Значения по умолчанию ближе к настройкам автора** (`DisplayPrefs` в `core`; те же числа в `ReaderSettings` в `reader_api`):

   | Настройка | Сейчас | Новое |
   |---|---|---|
   | `fontSize` | 18 | 22 |
   | `lineHeight` | 1.5 | 1.75 (середина ползунка 1–2.5) |
   | `dim` | 0 | 0.3 (30%) |
   | `textureOpacity` | 0.5 | 0.15 (15%) |

   Остальное не меняется. Тесты, которые проверяют старые значения по умолчанию, обновить.
