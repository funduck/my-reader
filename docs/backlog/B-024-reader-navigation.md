# B-024. Навигация читалки: левая панель по разделам и меню шестерёнки

**Статус:** открыт  
**Тип:** доработка  
**Связано с:** [B-003](B-003-reader-fullscreen.md), [B-014](B-014-cosmetics.md) (п. 2, 3), [B-019](B-019-text-highlights.md), `features/reader` (`reader_screen.dart`), `features/settings`

## Сейчас

- Левая панель (`_TocDrawer`) — только оглавление.
- Верхнее меню: «Day / Night», перевод по выделению, «Text», «Разминка» (шпаргалка), «History», «Settings» — всё отдельными иконками.

## Что хотим

### Левая панель по разделам

- **Оглавление** — внутри панели.
- **Шпаргалка** — внутри панели.
- **Переводы** — пункт открывает экран всей истории (нынешний экран истории).
- **Настройки** — пункт открывает экран настроек.

### Шестерёнка

Шестерёнка в верхнем меню открывает дропдаун:
- пункт «Настройки»;
- список всех кнопок и тогглов верхнего меню: день/ночь, перевод по выделению, шпаргалка, история, тогглы подсветок из [B-019](B-019-text-highlights.md). Любой работает прямо из дропдауна.

Любой пункт можно закрепить в верхнем меню (например, значком-булавкой). Наверху остаются шестерёнка и закреплённые пункты. Набор закреплённых сохраняется в настройках.

## Анализ

- Все действия меню описать одним списком (id, иконка, подпись, тип: кнопка или тоггл, действие) в `features/reader`. Из него строятся и дропдаун, и верхнее меню — тогда закрепление сводится к фильтру по id.
- Закреплённые id хранить в `DisplayPrefs` (или новых prefs читалки) в `core`, с миграцией и значением по умолчанию (например, день/ночь и шпаргалка).
- Шпаргалка сейчас — отдельный экран. Перенос в панель: решить, тот же виджет внутри `Drawer` или отдельная компактная версия. Ширина панели на телефоне мала для цитат.
- Кнопка «Text» по B-014 (п. 3) уходит из меню; в общий список её не включать.
- В полноэкранном режиме (B-003) меню видно только после тапа; дропдаун открывается так же.

## Вопросы

1. Какие пункты закреплены по умолчанию?
2. Шпаргалка в панели строится по кнопке внутри раздела или сразу при открытии раздела? (S-1: только по запросу пользователя.)

## Результат

Две задачи: (а) левая панель по разделам; (б) дропдаун шестерёнки и закрепление пунктов.
