# B-026. Склейка однокоренных слов и словоформ

**Статус:** ждёт примеров  
**Тип:** баг или доработка — станет ясно по примерам  
**Связано с:** [B-001](B-001-levels-noise.md) (п. 3), [B-019](B-019-text-highlights.md), `text_en`, `core` (`termKey`), `features/cheatsheet`, `features/reader`

## Проблема

При сканировании, подсветке и в шпаргалке встречались разные формы одного слова как разные слова. Конкретные случаи не записаны.

Сейчас словоформа приводится к лемме по таблице `en-forms` (`termKey`). Один ключ используют шпаргалка, подсветки и история.

## Что сделать

1. Собирать примеры: слово в тексте, где видно (шпаргалка, какая подсветка, история), что ожидалось. Добавлять сюда по мере появления.
2. По примерам решить, что это:
   - **баг лемматизации** — формы, которых нет в `en-forms`, или место, где ключ считается не через `termKey`;
   - **словообразование** — `happy` / `happiness` / `unhappy`: разные леммы одного гнезда. Нужен источник гнёзд (например, `derived terms` и этимология в Wiktionary) и решение, где их склеивать.
