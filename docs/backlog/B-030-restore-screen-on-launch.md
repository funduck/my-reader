# B-030. Восстанавливать экран после перезапуска

**Статус:** в задаче [T-125](../tasks/T-125.md), веха M11; вопрос 1 решён: только читалка и шпаргалка, из истории и настроек — книга, откуда пришли  
**Тип:** доработка  
**Связано с:** `app/app` (роутер, запуск), `features/reader`, `features/cheatsheet`, `features/history`

## Проблема

После перезапуска приложение открывается в библиотеке. Чтобы продолжить чтение, книгу надо открыть заново.

## Что хотим

При запуске открывается тот экран, где пользователь был: читалка (на сохранённом месте), шпаргалка, история. Библиотека — через «назад».

## Анализ

- Хранить последний маршрут (путь и параметры `go_router`) в локальном хранилище при каждой смене экрана. Модалки (перевод, лист «Text») не восстанавливаются.
- При запуске: маршрут есть и книга ещё в библиотеке — открыть его поверх библиотеки, чтобы «назад» работал. Книги нет или маршрут не разбирается — библиотека.
- Читалка уже открывается на сохранённой позиции, отдельно позицию хранить не нужно.
- Шпаргалка при восстановлении строится заново (уровень, кусок из профиля).
