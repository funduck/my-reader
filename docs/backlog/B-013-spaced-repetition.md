# B-013. Интервальное повторение

**Статус:** открыт  
**Тип:** новая функция  
**Связано с:** L-1, L-2, L-5, S-7 в [Requirements.md](../Requirements.md), [B-011](B-011-cheatsheet-controls.md), [B-012](B-012-reading-quiz.md)

## Что хотим

Колода повторения собирается **только из того, что пользователь сам добавил** «в повторение». Автоматически ничего не попадает.

Добавить можно из:
- теста ([B-012](B-012-reading-quiz.md));
- модалки перевода;
- истории;
- шпаргалки ([B-011](B-011-cheatsheet-controls.md)).

Там же элемент можно убрать из повторения.

Карточка: слово, перевод, предложение-контекст из книги (L-1). Расписание — алгоритм интервального повторения (FSRS или SM-2, L-2).

## Анализ

- `core`: карточка и её состояние расписания, порт хранилища; `storage_drift`: таблица и миграция.
- Алгоритм: FSRS точнее, SM-2 проще. Есть ли готовый Dart-пакет FSRS без лишних зависимостей — проверить.
- Экран повторения: показать слово с контекстом → показать ответ → оценка (как минимум «снова / хорошо»).
- Одна кнопка «В повторение / Убрать» — общий виджет для четырёх мест.
