# B-021. Перевод фраз через наш сервис

**Статус:** открыт  
**Тип:** новая функция (приложение и сервис)  
**Связано с:** [B-009](B-009-deepl-phrases.md) (раздел «Потом»), [B-025](B-025-llm-word-in-context.md) (слово в контексте через LLM), [Architecture-service.md](../Architecture-service.md), [Data-sources.md](../Data-sources.md)

## Что хотим

Фразы переводятся через `service/`, а не напрямую в DeepL из приложения.

Зачем:
- пользователю не нужен свой ключ DeepL, ключи лежат на сервисе;
- кэш: одна и та же фраза переводится один раз для всех;
- статистика запросов;
- разные провайдеры за одним API: DeepL, LLM, другие; можно менять без обновления приложения;
- перевод лучше: LLM учитывает контекст предложения и объясняет идиомы;
- склеивание вариантов фраз (`gave up` / `giving it up`) на сервере, см. B-009.

**Сервис недоступен:** если у пользователя есть свой ключ DeepL, приложение идёт в DeepL напрямую, как сейчас. Если ключа нет — понятное сообщение в модалке (как сейчас без ключа).

## Анализ

- **Сервис.** Новый эндпоинт перевода фразы: текст, контекст, направление. Кэш по нормализованной фразе и контексту, провайдеры за общим интерфейсом, учёт запросов. Сейчас сервис только размечает книги пакетами; это первый онлайн-эндпоинт. Нужно решить, где он работает, и что с доступом: без авторизации ключ на сервисе может съесть кто угодно.
- **Приложение.** Новый `LookupProvider` для фраз через сервис; порядок: сервис, затем DeepL со своим ключом. Хранение фраз не меняется (B-009).
- **Приватность.** На сервис уходит текст из книги пользователя. Учесть в статистике: что хранится и как долго.
- **Стоимость.** LLM и DeepL платные; лимиты на пользователя.
