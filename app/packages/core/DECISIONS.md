# Решения: core

Контракты и соглашения пакета, принятые в задачах. Общие правила — в [docs/tasks/AGENT.md](../../../docs/tasks/AGENT.md#принятые-решения).

- `TextQuote`: точная цитата плюс до 30 символов до и после, пробелы схлопнуты в один.
- `TextQuote.fromText` бросает `RangeError` при `start >= end` или выходе за границы; контекст считается после схлопывания пробелов.
- `CefrLevel.unknown` вне порядка: все сравнения с ним `false`, `compareTo` бросает `StateError`. Фильтр «выше уровня пользователя» — `level.isHarderThan(profile.level)`.
- `UserProfile.providerOrder` пустой — значит порядок регистрации провайдеров.
- Порты (`package:core/ports.dart`): `LookupProvider.lookup` при неудаче бросает `ProviderUnavailable` или `LookupNotFound` (sealed `LookupFailure`), цепочка идёт к следующему провайдеру; отмена — `CancelledException` через `CancelToken`. `BookFormatAdapter` принимает абсолютный путь `String path`, на битый файл бросает `FormatException`. `TextAnalyzer` и `LevelDictionary` синхронные, офсеты — UTF-16, полуинтервал.
- Толкование (T-045, `package:core/application.dart`): `ProviderChain.lookup` → sealed `ChainResult` (`ChainSuccess` / `ChainFailure`), таймаут 5 с на провайдера. `LookupSelection.call` → sealed `LookupOutcome` (`LookupAnswered` / `LookupUnanswered`, у второго `isNotFound`). Сбой провайдеров — значение, бросается только `CancelledException` (тогда ничего не пишется). Порядок: id из `providerOrder` первыми, остальные — в порядке регистрации. Событие и `Term` пишутся и при неудаче. Провайдеру уходит исходный текст; лемму `WiktionaryLookupProvider` берёт через свой хук `lemmas`, `LookupQuery` не меняется.
- Кусок для шпаргалки (T-052): `selectCheatSheetRange(book, from:, scope:)` → `CheatSheetRange?` (`start`, `end`, `text`, `wordCount`); `null` — нечего анализировать. Абзацы и главы склеиваются через `'\n\n'`, офсеты анализатора — относительно `text`. Слово — `[\p{L}\p{N}]+`, склейка через апостроф и дефис (`countWords`). Абзац, добивший бюджет, входит целиком. Абзац по `from` ищется только по `progression` (quote не используется) — если рендерер считает progression иначе, возможен сдвиг на соседний абзац.
- Шпаргалка (T-053): `BuildCheatSheet({generator, profiles, terms})`, `call(book, {from, cancel})` → `CheatSheet?`. `LevelCheatSheetGenerator({analyzer, levels})`: `text` элемента — лемма, `zipf` — из `WordLevel.zipf`, `example` — короткая цитата (`shortQuote`) вокруг первой словоформы из текста (не леммы), `translation` пустой. `unknown` отбрасывается. Порядок генератора (T-097): уровень ↓, Zipf ↑ (нет Zipf — самое редкое), число в куске ↓, первое вхождение ↑. Имя собственное — ни разу строчной и с заглавной не в начале предложения. Выученные леммы — `terms.watchAll().first`, любой статус. Константы — `cheat_sheet_config.dart` (`cheatSheetMaxItems = 15`).
- Шпаргалка, отбор (T-097): генератор отдаёт **всех** кандидатов с известным уровнем, без обрезки по уровню пользователя и по числу; у порта `CheatSheetGenerator` нет `userLevel`, `cheatSheetMaxItems` удалён. `BuildCheatSheet` тоже отдаёт всех, отбор делает экран: `selectCheatSheetItems(items, above:, limit:, hidden:)` — уровни строго выше `above`, без `hidden` (по `text`), `zipf` ↓ (без `zipf` — в конец), при равенстве порядок генератора, `limit == null` — все. `zipfBars(zipf)` → `int?` (1–5, `null` без `zipf`; пороги 5/4/3/2 — `zipfBars5..2` в `cheat_sheet_config.dart`). `shortQuote(sentence, word, {window = 7})` — до `window` слов с каждой стороны от первого вхождения `word` (целое слово, без учёта регистра), «…» на обрезанных краях; слово не найдено — всё предложение. Слова считаются по пробелам, знаки препинания остаются при слове.
- `UserProfile.cheatSheetLimit` (`int`, T-106): 1..500, по умолчанию `defaultCheatSheetLimit` = 10 (`minCheatSheetLimit`, `maxCheatSheetLimit`). «Все» больше нет, `cheatSheetLimits` удалён. Старый JSON: нет ключа — 10, `null` (раньше «все») — 500, число вне диапазона зажимается, не число — 10. `copyWith(cheatSheetLimit: 7)`.
- Уровень в модалке (T-051): `LookupOutcome.wordLevel` (`WordLevel`, обязательное поле обоих подтипов) — уровень из текущего `LevelDictionary` по тому же ключу, что `Term.normalized`, без `pos`; `outcome.level` = `wordLevel.level`, на запомненный `Term.level` не откатывается. Бейдж — `LevelBadge`: `C1`, оценка по частоте — `≈B2`, `unknown` — ничего.
- Настройки отображения (T-080): `UserProfile.display` — `DisplayPrefs` в том же JSON профиля, без миграции. Числа зажимаются в диапазон (константы `DisplayPrefs.min*/max*`) в конструкторе и `fromJson`; битые поля — умолчания. Цвета — ARGB `int`, `palette` — палитра текущего `mode`. Текстура в JSON: `{type: none}`, `{type: builtIn, id}`, `{type: file, path}`; пустой `id`/`path` — `NoTexture`.
- Шрифт (T-084): `DisplayPrefs.font` — `FontChoice?` (`{path, family}` в JSON), `fontFolder` — `String?`; без миграции, отсутствующие или битые поля — `null` (системный шрифт). `copyWith(font: () => …, fontFolder: () => …)`: `() => null` сбрасывает. `family` — отображаемое имя «Семейство Начертание», оно же имя для `FontLoader`; каждый файл — своё семейство, жирный и курсив синтезируются.
- Запись толкования (T-086): `LookupSelection.call` ничего не пишет; `record(outcome)` → `Future<Term>` пишет событие в журнал и обновляет `Term`. Повторный `record` того же события ничего не меняет (проверка по `Term.eventIds`). Журнал пишется раньше термина: если процесс упал между ними, повторный `record` запишет событие в журнал второй раз. В `LookupOutcome` больше нет поля `term`.
- Секреты (T-092): порт `SecretStore` (`read(key)`, `write(key, null)` удаляет) и константа `deeplApiKey` в `package:core/ports.dart`. Значения не попадают в `UserProfile`, базу и логи.
- Журнал фраз (T-093): `PhraseLookup` (`domain_lookup.dart`: `id` — `PhraseLookupId`, `text` как выделено, `translation`, `provider`, `at` UTC, `locator` обязателен, `sentence?`; `toJson`/`fromJson`, `at` — микросекунды). Порт `PhraseJournal` (`ports.dart`): `record` (тот же id — ничего), `watchAll()` (новые сверху), `byBook(BookId)` — `Future<List>`, `delete(id)` (неизвестный id — ничего). Варианты одной конструкции не склеиваются. `isSingleWord(text)` (`domain_lookup.dart`): после обрезки краёв без букв и цифр — одно слово `[\p{L}\p{N}]+` с внутренними `'`, `’`, `-`; то же правило, что `countWords` и `reader_simple`, но своя копия.
- Перевод выделением (T-089): `DisplayPrefs.translateOnSelect` (`bool`, по умолчанию `false`) в `copyWith`, `==`, JSON; старый профиль без поля или с не-`bool` читается как `false`, без миграции.
- Фраза (T-094, `package:core/application.dart`): `TranslatePhrase({provider, journal, clock, ids, analyzer})` — один провайдер фраз напрямую, без `ProviderChain` (его 5 с короче 10 с у DeepL). `call(text:, sentence:, locator:, cancel:)` → sealed `PhraseOutcome`: `PhraseTranslated` (`id`, `text` обрезан, `translation` — первый `Sense`, `provider`, `at`, `sentence`, `locator?`, `entry` → `PhraseLookup?`) или `PhraseFailed(kind, message)`; сбой — значение, бросается только `CancelledException`. Режим всегда `enRu`. `kind` (`PhraseFailureKind`) берётся из кода в начале `ProviderUnavailable.message` (`no_key`, `network`, `timeout`, `bad_key`, `quota`, `rate_limit`, `server_error`, остальное — `other`); `LookupNotFound` и пустой перевод — `notFound`. Длина (T-108): до запроса `call` проверяет обрезанный текст; если `analyzer.sentences` даёт больше одного предложения или текст длиннее `TranslatePhrase.maxLength` (500 символов, запас для текста без точек) — `PhraseFailed(kind: tooLong)`, провайдер не вызывается, журнал не трогается (DeepL считает квоту по символам). `call` ничего не пишет; `record(PhraseTranslated)` → `Future<bool>` пишет `PhraseLookup` в `PhraseJournal` с тем же id (повтор не дублирует), `false` без `locator`. Термины и `LookupJournal` не трогаются.
- Текущий пункт оглавления (T-100, `domain_books.dart`): `currentTocEntry(List<TocEntry> toc, int chapterIndex) → TocEntry?` — обход в порядке чтения (родитель, потом дети), результат — последний пункт с `chapter.index <= chapterIndex`; глава вне оглавления даёт предыдущий пункт, до первого пункта или пустое оглавление — `null`. Возвращает элемент самого списка (сравнивать `identical`).
- «Знаю» (T-098, `package:core/application.dart`): `SetTermStatus({terms, levels, ids})`, `call(normalized, status, {language = 'en'})` → `Term`. Нет термина — создаёт с `lookupCount: 0`, пустыми `eventIds` и уровнем из `LevelDictionary`; есть — меняет только `status`, при том же статусе ничего не пишет. Ключ термина — `termKey(analyzer, text)` (лемма слова или текст фразы в нижнем регистре), тот же, что пишет `LookupSelection.record`: вызывающий считает ключ сам. `record` статус не трогает (`copyWith` без `status`), счётчик и события добавляет и в термин, помеченный до первого толкования. `TermRepository` хранит термин без событий (контрактный тест). Снятая пометка (`learning`) термин не удаляет; шпаргалка по-прежнему прячет любой термин истории (T-053).
- Доля книги (T-104, `application.dart`): `bookFraction(at, {chapterCount, chapterLengths}) → double` в 0..1. С `chapterLengths` — (символы глав до текущей + `progression` × длина текущей) / длина книги; длина книги 0 — 0; глава за концом списка — без длины. Без них — прежняя `(chapter.index + progression) / chapterCount`, `chapterCount <= 0` — 0. `measureChapterLengths(book, {shouldStop}) → Future<List<int>?>` разбирает главы `spine` по очереди через `OpenedBook.chapter` и считает UTF-16-символы текста абзацев, заголовков, цитат и пунктов списков (картинки — 0); `shouldStop` проверяется перед каждой главой, `true` — результат `null`; нечитаемая глава — исключение, а не неполный список. Порт `OpenedBook` не менялся, длины нигде не хранятся. `SaveProgress.call(at, {chapterCount, chapterLengths})` считает `percent` через `bookFraction`; `chapterLengths` необязательны.
