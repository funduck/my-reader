# Решения: features/settings

Контракты и соглашения пакета, принятые в задачах. Общие правила — в [docs/tasks/AGENT.md](../../../../docs/tasks/AGENT.md#принятые-решения).

- Настройки (T-041): `packStoreProvider` переопределён через `overrideWith(_buildPackStore)` и следит за `serviceUrlProvider` (`StreamProvider<String?>` из профиля): смена адреса закрывает старый и создаёт новый `LazyHttpPackStore` (каталог `<applicationSupport>/packs` создаётся при первом обращении). Кто зависит от файлов пакетов, делает `ref.watch(packStoreProvider)`. `profileProvider` экспортируется из `features_settings`. После загрузки `en-levels` `CefrLevelDictionary` нужно открыть заново — это не делает `PacksController`, решает T-047/T-055. `defaultServiceUrl` продублирован в `features_settings` и `bootstrap.dart`.
- Словари и порядок (T-063): выбор файлов — `file_selector` за `dictionaryFilePickerProvider` (в тестах подменяется), `openFiles` без фильтра типов. Удаление словаря убирает его id из `UserProfile.providerOrder`. «Порядок толкования» — `ReorderableListView` по `orderedProviders` (та же сортировка, что в `ProviderChain`), перетаскивание сохраняет весь порядок. Параллельные импорт/удаление запрещает `DictionariesController.busy`.
- Чтение (T-081): `ReadingSection` — первая секция `SettingsScreen`; готовые палитры `dayPresets`/`nightPresets` (пары `(text, background)`), `contrastRatio` по WCAG, порог `minContrast` = 4.5 (предупреждение, не запрет), `parseHexColor` (`RRGGBB` или `#RRGGBB`, всегда непрозрачный). HEX сохраняется на каждое изменение, когда введено ровно шесть цифр; неверный ввод — ошибка под полем, профиль не меняется. Слайдеры пишут один раз на `onChangeEnd`. Ключи для тестов: `service-url`, `day-preset-<i>`, `night-preset-<i>`, `day-background`, `day-text`, `night-*`, `day-contrast-warning`, `dim`, `line-height`. Контролы размера/интервала/затемнения продублированы с панели читалки (фичи не импортируют друг друга).
- Текстура фона (T-082): в «Чтении» ряд образцов (`texture-none`, `texture-paper|noise|linen`, `texture-own`) и слайдер `texture-opacity` (пишет на `onChangeEnd`); образцы рисуются на фоне палитры текущего режима с тем же смешиванием, что читалка. `backgroundsDirectoryProvider` (без override бросает ошибку; `<applicationSupport>/backgrounds`, создаётся при первой записи) и `backgroundFilePickerProvider` (`file_selector.openFile`, `png/jpg/jpeg/webp`; в тестах подменяется). `importBackground(path, dir)` → sealed `BackgroundImported(path)` / `BackgroundTooLarge` (> 5 МБ, `maxBackgroundBytes`) / `BackgroundFailed`; копия — `<sha256>.<ext>` (расширение в нижнем регистре). Прежний свой файл удаляется, когда текстура сменилась (на другую свою, встроенную или «без»); трогаются только файлы внутри каталога фонов. Список встроенных `builtInTextureIds` продублирован из `reader_simple` (`builtInTextures`): фича не импортирует рендерер; asset — `packages/reader_simple/assets/textures/<id>.png`. Тесты с реальным файловым вводом-выводом в `testWidgets` крутят `pump` + `runAsync` по кругу (см. `settle` в `background_texture_test.dart`).
