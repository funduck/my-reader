# Решения: features/history

Контракты и соглашения пакета, принятые в задачах. Общие правила — в [docs/tasks/AGENT.md](../../../../docs/tasks/AGENT.md#принятые-решения).

- История (T-070): `HistoryScreen({onOpenLocation})` из `package:features_history/features_history.dart`; колбэк получает `event.query.locator` строки контекста, без колбэка строки не нажимаются. `historyProvider(BookId?)` собирает термины, весь журнал и книги в памяти; фильтр по книге — локальное состояние экрана, `LookupFilter` не используется. `lookupJournalProvider` и `termRepositoryProvider` проведены в `buildDeviceOverrides`.
- Вкладка фраз (T-095): `HistoryScreen` — две вкладки «Words» (прежний экран с фильтром по книге) и «Phrases». «Phrases» берёт `phraseJournalProvider.watchAll()` через `historyPhrasesProvider` (экспортируется), без фильтра по книге. Тап по фразе вызывает тот же `onOpenLocation(phrase.locator)`, что и у слов: маршрут и `Locator` общие. Свайп: `journal.delete`, «Undo» в `SnackBar` вызывает `journal.record` той же `PhraseLookup` (запись удалена, поэтому «тот же id — ничего» не мешает). Строка после свайпа скрывается локальным набором id до ответа потока. `phraseJournalProvider` нужен экрану только пока открыта вкладка «Phrases».
