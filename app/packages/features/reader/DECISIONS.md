# Решения: features_reader

Контракты и соглашения пакета, принятые в задачах. Общие правила — в [docs/tasks/AGENT.md](../../../../docs/tasks/AGENT.md#принятые-решения).

- Экран (T-020): `ReaderScreen({bookId, locator})`. `OpenBook` и `SaveProgress` (`core/application`) берутся через `openBookProvider`/`saveProgressProvider`, собранные из общих портов. `OpenBook` → sealed `OpenBookOutcome` (`BookOpened(book, opened, resumeAt)` / `BookNotFound` / `BookFileUnreadable`). `SaveProgress.call(locator, {chapterCount})`: `percent = (chapter.index + progression) / chapterCount`. Позиция: `locator` маршрута важнее сохранённой; `engine.load(book, bookId:, at:)`. Сохранение — через 1 с после последнего `PositionChanged`, при `paused`/`hidden`/`detached` и в `dispose` (потом движок закрывается). У `ReaderEngine` нет `currentLocator()`, поэтому при закрытии сохраняется последний `PositionChanged` (движок шлёт не чаще раза в 500 мс).
- Толкование (T-047): `WordTapped`/`TextSelected` экран отдаёт `lookupPresenterProvider` (`LookupPresenter(context, {text, at, sentence})`), потому что фича не может импортировать `lookup_sheet`. Без override бросает `PortNotWiredError` при тапе (ошибка логируется, читалка работает). Проводит `app` (`buildLookupOverrides`).
- Разминка (T-054): `ReaderScreen({onOpenCheatSheet})` — кнопка «Разминка» в AppBar видна только с колбэком; колбэк получает последний `PositionChanged`, иначе место открытия, иначе начало книги; перед вызовом позиция сохраняется.
- Подсветка (T-071): если `ReaderScreen` открыт с `locator` (из маршрута), после `engine.load` вызывается `engine.highlight([locator])`; без `locator` подсветки нет. Рисуется только при `quote` в локаторе (см. `reader_simple`).
- Кнопки шапки (T-101): `onOpenHistory`, `onOpenSettings` — необязательные `VoidCallback`, как `onOpenCheatSheet`; без них кнопок нет.
- Отображение (T-081): `readerSettingsFrom(DisplayPrefs)` (экспортируется) — `theme` по `mode`, `text`/`background` по `palette`, `BuiltInTexture(id)` → `AssetImage('packages/reader_simple/assets/textures/<id>.png')`, `FileTexture` → `FileImage`, `fontFamily` не трогается. `ReaderScreen` читает профиль через `profileRepositoryProvider` (теперь обязателен в тестах экрана), вызывает `applySettings` после `load` и при каждом изменении `display`. Кнопки шапки «Day / Night» (сразу сохраняет) и «Text» (нижняя панель: A−/A+, интервал, затемнение); правки панели применяются к движку сразу, в профиль пишутся через `displaySaveDebounce` = 300 мс, пока таймер идёт, поток профиля игнорируется. Ключи слайдеров: `line-height`, `dim`.
