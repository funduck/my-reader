# Решения: features_reader

Контракты и соглашения пакета, принятые в задачах. Общие правила — в [docs/tasks/AGENT.md](../../../../docs/tasks/AGENT.md#принятые-решения).

- Экран (T-020): `ReaderScreen({bookId, locator})`. `OpenBook` и `SaveProgress` (`core/application`) берутся через `openBookProvider`/`saveProgressProvider`, собранные из общих портов. `OpenBook` → sealed `OpenBookOutcome` (`BookOpened(book, opened, resumeAt)` / `BookNotFound` / `BookFileUnreadable`). `SaveProgress.call(locator, {chapterCount})`: `percent = (chapter.index + progression) / chapterCount`. Позиция: `locator` маршрута важнее сохранённой; `engine.load(book, bookId:, at:)`. Сохранение — через 1 с после последнего `PositionChanged`, при `paused`/`hidden`/`detached` и в `dispose` (потом движок закрывается). У `ReaderEngine` нет `currentLocator()`, поэтому при закрытии сохраняется последний `PositionChanged` (движок шлёт не чаще раза в 500 мс).
- Толкование (T-047, после T-088): `TextSelected` (слово и фраза) экран отдаёт `lookupPresenterProvider` (`LookupPresenter(context, {text, at, sentence})`), потому что фича не может импортировать `lookup_sheet`. Без override бросает `PortNotWiredError` при тапе (ошибка логируется, читалка работает). Проводит `app` (`buildLookupOverrides`).
- Разминка (T-054): `ReaderScreen({onOpenCheatSheet})` — кнопка «Разминка» в AppBar видна только с колбэком; колбэк получает последний `PositionChanged`, иначе место открытия, иначе начало книги; перед вызовом позиция сохраняется.
- Подсветка (T-071): если `ReaderScreen` открыт с `locator` (из маршрута), после `engine.load` вызывается `engine.highlight([locator])`; без `locator` подсветки нет. Рисуется только при `quote` в локаторе (см. `reader_simple`).
- Кнопки шапки (T-101): `onOpenHistory`, `onOpenSettings` — необязательные `VoidCallback`, как `onOpenCheatSheet`; без них кнопок нет.
- Отображение (T-081): `readerSettingsFrom(DisplayPrefs)` (экспортируется) — `theme` по `mode`, `text`/`background` по `palette`, `BuiltInTexture(id)` → `AssetImage('packages/reader_simple/assets/textures/<id>.png')`, `FileTexture` → `FileImage`, `fontFamily` не трогается. `ReaderScreen` читает профиль через `profileRepositoryProvider` (теперь обязателен в тестах экрана), вызывает `applySettings` после `load` и при каждом изменении `display`. Кнопки шапки «Day / Night» (сразу сохраняет) и «Text» (нижняя панель: A−/A+, интервал, затемнение); правки панели применяются к движку сразу, в профиль пишутся через `displaySaveDebounce` = 300 мс, пока таймер идёт, поток профиля игнорируется. Ключи слайдеров: `line-height`, `dim`.
- Текстура (T-082): `readerSettingsFrom` для `FileTexture` с отсутствующим файлом возвращает `texture == null` и пишет `warning`; проверка — `File.existsSync()` при каждом переводе настроек.
- Подсветка тапа (B-004): пока открыт перевод (`LookupPresenter` не завершился), экран вызывает `engine.highlight([..._marks, at])`, после закрытия — `engine.highlight(_marks)`; `_marks` — метка из маршрута (T-071) или пусто. Цвет тот же, что у метки из истории (`ReaderStyle.highlight`).
- Шрифт (T-084): `readerSettingsFrom` ставит `fontFamily` из `DisplayPrefs.font`; файла нет — `null` и `warning`. `ReaderScreen` вызывает `loadUserFont` перед первым `applySettings` и при смене шрифта в профиле (применяет, только если за время загрузки настройки не сменились). `bootstrap.dart` загружает сохранённый шрифт до первого кадра.
- Полноэкранное чтение (T-087): только Android и iOS (`defaultTargetPlatform`); на остальных AppBar виден всегда, `ViewTapped` игнорируется, `SystemChrome` не вызывается. На телефоне при открытии меню скрыто (`SystemUiMode.immersiveSticky`), `ViewTapped` переключает меню: AppBar и панели показываются (`edgeToEdge`) и прячутся вместе; начало прокрутки пальцем (`ScrollStartNotification` с `dragDetails`) прячет показанное. AppBar лежит поверх текста (`extendBodyBehindAppBar`), не убирается из `Scaffold` и уезжает вверх `AnimatedSlide` (200 мс); скрытый, он не получает касаний, фокуса и чтения с экрана. Верхний отступ текста — `viewPaddingOf(context).top`, запомненный при скрытом меню и неизменный при показанном (текст не прыгает); подставляется в `MediaQuery.padding.top` тела. Вызовы `SystemChrome` — за интерфейсом `SystemChromeGateway` с `systemChromeProvider` (по умолчанию `PlatformSystemChrome`, в тестах — фейк). `dispose` и кнопки «History», «Settings», «Разминка» возвращают `edgeToEdge`; после возврата на экран (`ModalRoute.isCurrent`) и при `AppLifecycleState.resumed` режим выставляется заново по состоянию меню. Листы (перевод, быстрые настройки) панели не трогают. Тесты, которые жмут кнопки AppBar, на телефонном варианте сначала показывают меню тапом по полю или идут с `TargetPlatform.macOS`.
