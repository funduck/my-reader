# Решения: features/cheatsheet

Контракты и соглашения пакета, принятые в задачах. Общие правила — в [docs/tasks/AGENT.md](../../../../docs/tasks/AGENT.md#принятые-решения).

- Экран разминки (T-054): `CheatSheetScreen({bookId, onRead, from, onWordTap})` из `package:features_cheatsheet/features_cheatsheet.dart`. `from == null` — сохранённая позиция, иначе начало книги. `onWordTap(context, LookupQuery)` — вызывающий показывает `showLookupSheet` (`router.dart`), так что фича не зависит от `lookup_sheet`; `LookupQuery` содержит слово, предложение из шпаргалки, режим из профиля и `sheet.from` как `locator`. Без `onWordTap` строки не нажимаются.
- `cheatSheetProvider((bookId:, from:))` открывает книгу через `OpenBook` из портов, строит `BuildCheatSheet(generator: cheatSheetGeneratorProvider, ...)`, закрывает книгу. Лист строится один раз и содержит всех кандидатов (`CheatSheetLoad.sheet`); профиль провайдер не слушает (только `get()` для режима и куска). Ошибка книги — `AsyncError`, экран пишет «Не удалось подготовить разминку.». `itemGlossProvider((text:, mode:))` берёт первое значение через `ProviderChain` без записи в журнал (в историю пишется только тап).
- Маршрут: `/cheatsheet/:bookId?locator=<json>` (`encodeLocatorParam`), «Читать» делает `pop`, а без истории — `go` в читалку. Тексты на русском, без l10n.
- В тестах провайдеры с фейками завершаются только через `tester.runAsync` (два круга: лист вместе с профилем, затем толкования строк). Чтение потока фейка (`terms.watchAll().first`) в теле теста — тоже через `tester.runAsync`, иначе тест зависает.
- Отбор, уровень, лимит, «Знаю» (T-099): показ строится в `cheatSheetItemsProvider(request)` (`AsyncValue<List<CheatSheetItem>>`) — `selectCheatSheetItems` над листом из `cheatSheetProvider`, уровнем и `cheatSheetLimit` из `cheatSheetProfileProvider` (поток `ProfileRepository.watch()`) и множеством `cheatSheetKnownProvider(request)` (`hidden` по `CheatSheetItem.text`, живёт, пока открыт экран). Смена уровня, лимита и «Знаю» пересчитывает только его: книга и генератор не вызываются заново. Тест считает вызовы фейкового генератора.
- Над списком — `SegmentedButton`: «Выше уровня» A2/B1/B2/C1 (пишет `UserProfile.level`, то же значение, что «My level» в настройках; если уровень A1/C2, выбранного сегмента нет) и числовое поле «Слов» (T-106; `TextField`, только цифры, по умолчанию 10; пишет `UserProfile.cheatSheetLimit`, когда фокус уходит из поля или нажата Enter; пустое или 0 — возврат к сохранённому, больше 500 — 500). Запись — `profileRepositoryProvider.get()` + `save(copyWith)`, список обновляется по потоку профиля.
- Строка: уровень и `FrequencyBars(bars: zipfBars(item.zipf))` (5 полосок растущей высоты, заполнены первые `bars`; без `zipf` виджета нет; `Semantics` «частотность N из 5»), цитата — `item.example` как есть (её режет генератор, `shortQuote`), справа кнопка «Знаю».
- «Знаю» (`CheatSheetKnown.markKnown(item)`): слово сразу в `hidden`, затем `setTermStatusProvider(termKey(analyzer, item.text), known)` — ключ тот же, что пишут толкования. Ошибка записи — слово возвращается в список, `warning` в лог. `SnackBar` «Undo» (`undo(item)`): слово обратно в список, статус `learning`. Скрытые отметки не переживают экран: следующий лист сам прячет известные термины (`BuildCheatSheet`).
- `SnackBar` с «Undo» (T-105): `persist: false` обязателен. Во Flutter 3.50 у `SnackBar` с `action` по умолчанию `persist: true`, и он не закрывается по таймеру.
- Снимок шпаргалки (T-118): экран держит `ref.watch(cheatSheetSnapshotSaverProvider(request))` (внутренний, не экспортируется). Он слушает `cheatSheetItemsProvider` и пишет `CheatSheetSnapshot(book, clock.now().toUtc(), тексты показанных строк)` в `cheatSheetLogProvider`: когда список впервые показан и при каждом изменении набора слов (уровень, лимит, «Знаю», Undo) — в логе всегда последний показанный список. Если слова те же (профиль перевыдан) — не пишет; пока список грузится или в ошибке — не пишет; пустой показанный список пишется как пустой снимок. Сбой записи — `warning` в лог, экран не страдает, следующее изменение пробует снова. Тестам экрана нужны `cheatSheetLogProvider` и `clockProvider` (иначе запись молча не происходит).
