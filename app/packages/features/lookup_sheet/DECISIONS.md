# Решения: features/lookup_sheet

Контракты и соглашения пакета, принятые в задачах. Общие правила — в [docs/tasks/AGENT.md](../../../../docs/tasks/AGENT.md#принятые-решения).

- Модалка (T-046): `showLookupSheet(context, query, {onOpenSettings})` из `package:lookup_sheet/lookup_sheet.dart`; про go_router не знает — вызывающий передаёт `() => context.go(Routes.settings)`. `lookupSelectionProvider` собирается в фиче из портов `features_common`, в bootstrap подключаются только порты. Переключатель EN→RU/EN→EN в шапке — только для открытого окна, в профиль не пишется. Любой `LookupUnanswered` с `!isNotFound` — «нет словаря» с кнопкой в настройки. Тексты без l10n.
- Уровень в модалке (T-051): `LookupOutcome.wordLevel` (`WordLevel`, обязательное поле обоих подтипов) — уровень из текущего `LevelDictionary` по тому же ключу, что `Term.normalized`, без `pos`; `outcome.level` = `wordLevel.level`, на запомненный `Term.level` не откатывается. Бейдж — `LevelBadge`: `C1`, оценка по частоте — `≈B2`, `unknown` — ничего.
- Выбор провайдера и HTML (T-063): `lookupOutcomeProvider` с ключом `LookupRequest = ({LookupQuery query, ProviderId? provider})`; выбранный провайдер спрашивается один, без отката; список «Авто» + провайдеры текущего режима, показывается при двух и больше; смена режима сбрасывает неподходящий выбор. `SimpleHtml` (`parseSimpleHtml`, `looksLikeHtml`): b/strong, i/em, br, p, сущности; остальные теги отбрасываются с сохранением текста, script/style — целиком. Через него рисуется только толкование с тегами.
- HTML-блоки (T-102): `SimpleHtml` переносит строку на открытии и закрытии `div`, `p`, `ol`, `ul`, `li`, `h1`–`h6`, `tr`, `blockquote` и на `br`; пустые строки схлопываются, пробелы в конце строки и ведущие/хвостовые переводы строк убираются. `li` — `1.` в `ol`, `•` в `ul` (и вне списка); вложенный список сдвинут на два пробела за уровень. Номер сенса «N. » — обычный префикс: идёт перед первой строкой статьи, продолжение строк с отступом от нуля.
- Запись по времени (T-086): `minLookupViewDuration` = 2 с. Готовый результат (`LookupAnswered` и `LookupUnanswered`) обёрнут в `_RecordAfterView` с ключом по id события; таймер стартует при показе результата, по нему вызывается `LookupSelection.record`, сбой записи — `warning`. Таймер отменяется, как только модалка начинает закрываться (обратная анимация маршрута), а не после анимации. Другой провайдер или режим — новое событие и новый таймер; уже записанное остаётся.
- Шапка и переключатель режима (T-090): первая строка — слово слева, справа `LevelBadge` и кнопка режима (`RU` / `EN` = текущий режим, ключ `lookup-mode-toggle`, tooltip и `Semantics` «English → Russian» / «English → English»); сразу под строкой — перевод; выбор провайдера — под результатом. `LevelBadge` больше не в `_Answer`: берётся из `wordLevel` показанного (или базового) результата. Кнопка скрыта, если ни один провайдер не `supports` другой режим; неактивна (`onPressed: null`), если фоновый запрос другого режима дал «не найдено»; из другого режима назад можно всегда.
- Фоновый запрос другого режима (T-090): `otherModeProbeProvider(LookupQuery)` — по одному офлайн-провайдеру (`!info.isOnline`, `supports`) в порядке регистрации через `LookupSelection(provider: id)`; первый `LookupAnswered` — результат, иначе последний «не найдено», иначе `null` (нет офлайн-провайдеров или `unavailable`) — тогда кнопка активна, а нажатие делает обычный запрос. Цепочка исходного режима остаётся под наблюдением, поэтому переключения туда-сюда не повторяют запросы. Фоновый результат пишется в историю только как любой показанный: через `_RecordAfterView` (2 с на экране, T-086). Выбор провайдера в другом режиме — обычный новый запрос.
- Фраза (T-094): `LookupSheet` для текста, где `isSingleWord` ложно, показывает `_PhraseView`: словарей, шапки с уровнем, переключателя режима и выбора провайдера нет. Заголовок — фраза, `maxLines: 3` с `…`; под ним перевод и имя провайдера. `phraseProviderProvider` (`Provider<LookupProvider>`, без override — `PortNotWiredError`) — провайдер фраз, в `lookupProvidersProvider` он не входит; `translatePhraseProvider` собирает `TranslatePhrase` из него и портов `features_common` (включая `textAnalyzerProvider`); `phraseOutcomeProvider(LookupQuery)` — один запрос на фразу, `ref.invalidate` повторяет. Сбои по `PhraseFailureKind`: `noKey` — «Phrase translation needs a DeepL API key» и «Open settings» (`onOpenSettings`); `badKey` — «Open settings» и «Retry»; `notFound` — только текст; `tooLong` (T-108, больше одного предложения или длиннее 500 символов) — «Select one sentence at most», без «Retry» и без запроса; остальные — текст по коду и «Retry». Запись — тот же `_RecordAfterView` (теперь с колбэком `record` вместо `LookupOutcome`), 2 с на экране, только для `PhraseTranslated`; сбои не пишутся.
- «Знаю» в модалке (T-098): для одного слова в шапке после уровня — `FilterChip` «Знаю» (`lookup-known-toggle`, `KnownToggle`); у фраз его нет. Ключ термина — `termKey(textAnalyzerProvider, текст)`, состояние — `termStatusProvider(key)` из `TermRepository.watchAll()`, так что пометка из истории или шпаргалки видна сразу. Нажатие вызывает `setTermStatusProvider` (`features_common`): `known` ↔ `learning`, работает и пока идёт запрос, и раньше 2-секундной записи (термин создаётся без толкований, `record` потом добавит счётчик, статус сохранится). Сбой записи — `warning`. Модалке теперь нужны порты `textAnalyzerProvider`, `termRepositoryProvider`, `levelDictionaryProvider`, `idGeneratorProvider`; в тестах — `test/term_support.dart`.
- Высота модалки (T-110, B-018 вариант Б): `showLookupSheet` кладёт `LookupSheet` в `DraggableScrollableSheet(expand: false)`: открывается на `lookupSheetInitialSize` (0,66) высоты под ручкой, тянется до `lookupSheetMaxSize` (0,9), стянутая до 0,25 (минимум по умолчанию) закрывается. Под короткое содержимое не сжимается, смена режима высоту не меняет. `LookupSheet({scrollController})` — контроллер листа; без него (виджет сам по себе, как в тестах) прежний предел 70 % экрана. Шапка со словом и переключателем прокручивается вместе с содержимым. Тест: `test/sheet_height_test.dart`.
- Лейблы и кнопки (T-126): `LevelBadge` теперь из `features_common` (общий `InfoLabel`), файл `level_badge.dart` удалён. «Знаю» — `ToggleButton` (ключ `lookup-known-toggle` на нём; в тестах `tester.widget<ToggleButton>(...).selected`), включён — с галочкой. Кнопка режима `lookup-mode-toggle` осталась `OutlinedButton` (теперь `.icon`): добавлена иконка `swap_horiz`, чтобы было видно, что это кнопка; текст `RU`/`EN` и `Semantics` те же.
