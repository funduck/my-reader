# Решения: storage_drift

Контракты и соглашения пакета, принятые в задачах. Общие правила — в [docs/tasks/AGENT.md](../../../docs/tasks/AGENT.md#принятые-решения).

- `storage_drift` (T-007): `openDatabase(path)` / `openInMemory()` → `AppDatabase` с геттерами `bookRepository`, `progressRepository`, `profileRepository`. `Locator` и `UserProfile` — JSON-текст, `DateTime` — микросекунды UTC. FK нет, каскад прогресса — в `remove`. `*.g.dart` коммитятся (`dart run build_runner build`). Новая таблица: `tables.dart` → `@DriftDatabase` → поднять `currentSchemaVersion` и `onUpgrade` → `drift_dev schema dump` → `schema generate` в `test/generated` с переименованием выхода в `*.g.dart` (иначе `strict_raw_type` в сгенерированном коде) → тест миграции в `schema_test.dart`.
- Журнал и термины (T-008): порты `core` не менялись (`record`/`get`/`watch(filter)`, `find`/`watchAll`/`save`). `AppDatabase.lookupJournal` → `DriftLookupJournal` (+`byTerm`), `AppDatabase.termRepository` → `DriftTermRepository` (+`upsert` в транзакции, `byLemma`, `allLemmas({language, status})` — все статусы, если `status` не задан). `LookupSelection` (T-045) пока делает `find` + `save`, а не `upsert`. Схема v2: `lookup_events`, `terms` (уникальный `(normalized, language)`), `term_events` (`position` — порядок `eventIds`). Журнал — `at` ↓, затем `rowid` ↓.
- Журнал фраз (T-093): схема v3, таблица `phrase_lookups` (`phrase` — текст, `locator` — JSON, `book_id` скопирован для фильтра; индексы по `at` и `book_id`). `AppDatabase.phraseJournal` → `DriftPhraseJournal`; `record` — `insertOrIgnore`. Миграция `from < 3` только создаёт таблицу и индексы; тест `schema_test.dart` кладёт в v2 книгу, событие и термин и проверяет, что они на месте. Файлы `test/generated/schema*.dart` после `schema generate` нужно переименовать в `*.g.dart` вместе с импортами внутри `schema.g.dart`.
- Последняя шпаргалка (T-118): схема v4, таблица `cheat_sheet_snapshots` (`book_id` — ключ, `shown_at` — микросекунды UTC, `lemmas` — JSON-массив строк через `StringListConverter`). `AppDatabase.cheatSheetLog` → `DriftCheatSheetLog`: `save` — `insertOnConflictUpdate`, `watch` — `watchSingleOrNull().distinct()` (drift перезапускает запрос при любой записи в таблицу, `distinct` оставляет только свою книгу). `BookRepository.remove` удаляет и снимок книги в той же транзакции, как прогресс. Миграция `from < 4` только создаёт таблицу; тест `schema_test.dart` кладёт в v3 книгу и фразу и проверяет, что они на месте, а журнал шпаргалки пуст и работает. Файлы `schema*.g.dart` перегенерированы по рецепту выше (`dump` → `generate` → переименование в `*.g.dart`).
- `DriftProfileRepository.update` (T-120) — в `transaction`: drift выполняет транзакции одной базы по очереди. `FakeProfileRepository.update` — один синхронный шаг в памяти.
