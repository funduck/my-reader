# Решения: format_epub

Контракты и соглашения пакета, принятые в задачах. Общие правила — в [docs/tasks/README.md](../../../docs/tasks/README.md#принятые-решения).

- `format_epub` (T-010): `ChapterRef.href` — путь записи внутри контейнера (`OEBPS/text/ch1.xhtml`), уже разрешённый относительно OPF; `linear="no"` включается. С T-013 `ChapterRef.index` — позиция главы, а `href` главы — цель из оглавления (см. ниже). Обложка — через `EpubFormatAdapter.readCover(path)` и `EpubBook.cover()`, в `BookMetadata` её нет. Для ссылок из nav/NCX/XHTML — `resolveEntryPath(base, href)`.
- Оглавление EPUB (T-011): `TocEntry.chapter.href` — `путь#фрагмент` (фрагмент как в источнике, без отдельного поля), `index` — позиция главы (с T-013); несколько пунктов могут делить один `index`. Пункты вне spine и внешние ссылки отбрасываются, их дети поднимаются. Источник: nav → NCX → по пункту на spine.
- XHTML → `ContentDocument` (T-012): `convertXhtml(xhtml, path:)` → `ChapterContent(document, anchors)`. В `ContentDocument` нет id элементов, поэтому `anchors` — побочная таблица id → индекс верхнего блока. Внутренние ссылки — `путь#фрагмент`, картинки — путь записи. Вложенные списки уплощаются, картинка внутри абзаца режет его на части.
- Главы EPUB (T-013): `book.spine` — по пункту оглавления верхнего уровня; `ChapterRef.index` — позиция главы (не файла), в `toc` вложенный пункт получает индекс родительской главы. `href` главы — цель из оглавления (`путь` или `путь#фрагмент`). Текст до первого пункта — отдельная первая глава. `chapter(ref)` ищет только по `href`: начало главы — эта глава, любое другое место (файл, `файл#фрагмент`, вложенный пункт) — глава, которая его содержит; неизвестный путь — `FormatException`. Фрагмент без id — начало файла. Весь XML разбирается с HTML-сущностями (`XmlDefaultEntityMapping.html()`).
