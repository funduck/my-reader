# Решения: app

Проводка в `bootstrap.dart`, `main.dart` и `router.dart`. Общие правила — в [docs/tasks/AGENT.md](../../docs/tasks/AGENT.md#принятые-решения). Контракты фич — в их `DECISIONS.md`.

- Библиотека (T-019): `ImportBook({adapters, books, clock, ids, directory, hash})`, `call(path)` → sealed `ImportOutcome` (`BookImported` / `BookAlreadyImported` / `BookUnsupported`); бросается только `FileSystemException`. Файл — `<directory>/<hash>.<format>`, хеш внедряется (`sha256OfFile` в `features_library`). `main.dart` асинхронный: `bootstrap(overrides: [...buildOverrides(), ...await buildDeviceOverrides()])`; `buildDeviceOverrides` открывает drift в `<applicationSupport>/my_reader.sqlite` и подключает репозитории, `EpubFormatAdapter`, `booksDirectoryProvider` (`<applicationSupport>/books`). Новые устройство-зависимые порты добавляются туда же. `LibraryScreen({onOpenBook})` — навигацию делает `router.dart`.
- Настройки (T-041): `packStoreProvider` переопределён через `overrideWith(_buildPackStore)` и следит за `serviceUrlProvider` (`StreamProvider<String?>` из профиля): смена адреса закрывает старый и создаёт новый `LazyHttpPackStore` (каталог `<applicationSupport>/packs` создаётся при первом обращении). Кто зависит от файлов пакетов, делает `ref.watch(packStoreProvider)`. `profileProvider` экспортируется из `features_settings`. После загрузки `en-levels` `CefrLevelDictionary` нужно открыть заново — это не делает `PacksController`, решает T-047/T-055. `defaultServiceUrl` продублирован в `features_settings` и `bootstrap.dart`.
- История (T-070): `HistoryScreen({onOpenLocation})` из `package:features_history/features_history.dart`; колбэк получает `event.query.locator` строки контекста, без колбэка строки не нажимаются. `historyProvider(BookId?)` собирает термины, весь журнал и книги в памяти; фильтр по книге — локальное состояние экрана, `LookupFilter` не используется. `lookupJournalProvider` и `termRepositoryProvider` проведены в `buildDeviceOverrides`.
- Читалка (T-020): порт `readerEngineFactoryProvider` (`features_common`, тип `ReaderEngineFactory` из `reader_api`) подключается в `buildDeviceOverrides` (`SimpleReaderEngine.new`), а не в `buildOverrides`: тесты маршрута подставляют свой фейковый движок. Параметр `locator` маршрута `Routes.reader` — JSON `Locator.toJson` (`encodeLocatorParam` из `features_reader`); ссылка — `Routes.readerAt(id, locator: encodeLocatorParam(l))`; битое значение — открытие с сохранённого места. Экран маршрута с ключом `bookId|locator`. В тестах уровня app запись в drift завершается только через `tester.runAsync`; после `paused` нужно отправить `resumed`, иначе `router.go` не рисует кадр.
- Движок и анализатор (T-018): `SimpleReaderEngine({required TextAnalyzer analyzer})`. В `buildDeviceOverrides` фабрика — `() => SimpleReaderEngine(analyzer: const EnglishTextAnalyzer())` без лемматизатора: движку нужны только границы предложений. T-047 может перевести её на `textAnalyzerProvider`.
- Тап → толкование (T-047): `buildLookupOverrides(packsDirPath, {providers})` в `bootstrap.dart` — `textAnalyzerProvider` (`EnglishTextAnalyzer` + `PackFormsLemmatizer`), `levelDictionaryProvider` (`PackLevelDictionary`), `lookupProvidersProvider` (`WiktionaryLookupProvider` на `packStoreProvider`, хук лемм — анализатор), `lookupPresenterProvider` (профиль → `LookupQuery` → `showLookupSheet`, «настройки» → `Routes.settings`). `PackFormsLemmatizer`/`PackLevelDictionary` открывают пакет `<packs>/<id>.sqlite` лениво при первом обращении после установки, поэтому «открыть `en-levels` заново» (T-041) не нужно; замену файла уже открытого пакета они не видят до перезапуска. Фабрика движка в `buildDeviceOverrides` берёт `textAnalyzerProvider`. Тест: `app/test/lookup_wiring_test.dart`.

- Разминка (T-054): `router.dart` ведёт кнопку читалки на `/cheatsheet/:bookId?locator=<json>` и передаёт в `CheatSheetScreen` `onWordTap` → `showLookupSheet` (импорт `lookup_sheet` только здесь). `cheatSheetGeneratorProvider` до T-055 не проведён: на устройстве экран разминки показывает ошибку. `screens/placeholder_screen.dart` больше не используется.
- История → читалка (T-071): `Routes.history` строит `HistoryScreen(onOpenLocation: ...)`, переход — `context.push(Routes.readerAt(book, locator: encodeLocatorParam(l)))`. `integration_test/history_to_reader_test.dart` запускает человек на macOS; тот же сценарий на фейковом движке — `test/history_to_reader_test.dart`. В widget-тесте `database.close()` внутри `runAsync` зависает: БД не закрывать, после размонтирования сделать `pump(1 ms)`.
- Связка разминки (T-055): `cheatSheetGeneratorProvider` проведён в `buildLookupOverrides` — `LevelCheatSheetGenerator(analyzer: textAnalyzerProvider, levels: levelDictionaryProvider)`, то есть тот же `PackLevelDictionary`, что у модалки; второй `CefrLevelDictionary` не открывается. Уровень и размер куска `BuildCheatSheet` читает из профиля при каждом построении листа (`cheatSheetProvider` — autoDispose), поэтому смена в настройках действует без перезапуска. Тесты: `test/cheatsheet_wiring_test.dart` (генератор на мини-пакете `service/fixtures/packs/en-levels-*.sqlite`, смена уровня и куска, замер 10 страниц < 1 с через `Stopwatch` в обычном `test`, сквозной сценарий на фейковых краях); `integration_test/cheatsheet_test.dart` запускает человек на macOS. Замер сделан на мини-пакете, на полном `en-levels` его нужно подтвердить на устройстве (U-4).
- Сквозной тест толкования (T-048): `integration_test/lookup_e2e_test.dart` (человек, macOS) и `test/lookup_e2e_test.dart`; общие части — `test/support/lookup_e2e.dart` (`LookupFixture`, `OfflineClient`). Офлайн — override `packStoreProvider` на `HttpPackStore` с клиентом, который бросает на любом запросе; вместе с `buildOverrides()` это нельзя (двойной override), тест сам задаёт `clockProvider`, `idGeneratorProvider` и `buildLookupOverrides(packsDir)`. Порог 300 мс — от выхода `WordTapped` из движка до кадра с толкованием: движок держит тап `kDoubleTapTimeout` (300 мс, T-018), время от касания только печатается. Мини-пакеты вшиты в `test/support/pack_fixtures.dart` (base64: песочница macOS-приложения не читает `service/fixtures`), сверку с файлами делает `test/pack_fixtures_test.dart`.
