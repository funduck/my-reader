# Решения: app

Проводка в `bootstrap.dart`, `main.dart` и `router.dart`. Общие правила — в [docs/tasks/README.md](../../docs/tasks/README.md#принятые-решения). Контракты фич — в их `DECISIONS.md`.

- Библиотека (T-019): `ImportBook({adapters, books, clock, ids, directory, hash})`, `call(path)` → sealed `ImportOutcome` (`BookImported` / `BookAlreadyImported` / `BookUnsupported`); бросается только `FileSystemException`. Файл — `<directory>/<hash>.<format>`, хеш внедряется (`sha256OfFile` в `features_library`). `main.dart` асинхронный: `bootstrap(overrides: [...buildOverrides(), ...await buildDeviceOverrides()])`; `buildDeviceOverrides` открывает drift в `<applicationSupport>/my_reader.sqlite` и подключает репозитории, `EpubFormatAdapter`, `booksDirectoryProvider` (`<applicationSupport>/books`). Новые устройство-зависимые порты добавляются туда же. `LibraryScreen({onOpenBook})` — навигацию делает `router.dart`.
- Настройки (T-041): `packStoreProvider` переопределён через `overrideWith(_buildPackStore)` и следит за `serviceUrlProvider` (`StreamProvider<String?>` из профиля): смена адреса закрывает старый и создаёт новый `LazyHttpPackStore` (каталог `<applicationSupport>/packs` создаётся при первом обращении). Кто зависит от файлов пакетов, делает `ref.watch(packStoreProvider)`. `profileProvider` экспортируется из `features_settings`. После загрузки `en-levels` `CefrLevelDictionary` нужно открыть заново — это не делает `PacksController`, решает T-047/T-055. `defaultServiceUrl` продублирован в `features_settings` и `bootstrap.dart`.
- История (T-070): `HistoryScreen({onOpenLocation})` из `package:features_history/features_history.dart`; колбэк получает `event.query.locator` строки контекста, без колбэка строки не нажимаются. `historyProvider(BookId?)` собирает термины, весь журнал и книги в памяти; фильтр по книге — локальное состояние экрана, `LookupFilter` не используется. `lookupJournalProvider` и `termRepositoryProvider` проведены в `buildDeviceOverrides`.
- Читалка (T-020): порт `readerEngineFactoryProvider` (`features_common`, тип `ReaderEngineFactory` из `reader_api`) подключается в `buildDeviceOverrides` (`SimpleReaderEngine.new`), а не в `buildOverrides`: тесты маршрута подставляют свой фейковый движок. Параметр `locator` маршрута `Routes.reader` — JSON `Locator.toJson` (`encodeLocatorParam` из `features_reader`); ссылка — `Routes.readerAt(id, locator: encodeLocatorParam(l))`; битое значение — открытие с сохранённого места. Экран маршрута с ключом `bookId|locator`. В тестах уровня app запись в drift завершается только через `tester.runAsync`; после `paused` нужно отправить `resumed`, иначе `router.go` не рисует кадр.
